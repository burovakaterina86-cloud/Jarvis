# Фото Катерины — для каруселей, лид-магнитов, обложек

Её слова (2026-09-25): «положи их в проект чтобы можно было использовать и для лид магнитов
и для каруселей. одежду и прическу можно менять».

Одежда и причёска на кадрах разные — это всё она. Подбирай кадр под настроение материала,
а не по одному «главному».

## Главный образец внешности — `portraits/face-main-selfie-black.jpg` (с 2026-09-25)

Её фото 2026-09-25: анфас, резкое, чёрный лонгслив, тёмный интерьер. Идёт первым (IMAGE 1) в каждую генерацию с ней
и **само подходит для тёмной обложки целиком — без вырезания и без генерации** (пример:
`content/2026-09-25-golos-karusel/visuals/cover-dark-selfie.png`). Её правило: карусели с её фото
JARVIS делает сам, без её участия — фото каждый раз она не присылает. Правило о неизменности и резкости лица —
`essa-ai/IDENTITY_LOCK.md`, п. 5.

## Прежний образец — `portraits/face-reference.jpg`

Её селфи 2026-09-25: «сохрани это фото моё и на основе него делай фотографии». **Любая генерация
с ней — только с этим файлом в `--ref`** (`python -m integrations.visuals.imagegen … --ref
essa-ai/photo/portraits/face-reference.jpg`). Одежду, позу, причёску, ракурс — можно менять.
Внешность и все черты лица — сохранить. Возраст не добавлять. Для лид-магнитов и каруселей одинаково.
Копия лежит в навыке лид-магнитов: `.claude/skills/lead-magnet-agent/assets/author/face-reference.jpg`.

**Главное правило — `essa-ai/IDENTITY_LOCK.md` (её инструкция 2026-09-25).** Порядок: реальное фото + дизайн →
правка её фото (`imagegen --edit`) → полная генерация по её фото (`imagegen --her`), только если первые два не подходят.
Проверка сходства исходник → результат обязательна. Подробно — навык `carousel-instagram`, шаг 3.

**Все пять образцов передаются всегда** (её слова 2026-09-25: «лицо вообще не моё… у меня не такое пухлое лицо»):
`portraits/face-front-studio.png` (самый точный анфас), `portraits/face-selfie-2.jpg`, `face-reference.jpg` и профили.
Черты лица (узкое, скулы, чёткая челюсть — не делать круглее) описаны в `imagegen.KEEP_FACE`.

Профили (её фото 2026-09-25, «для боковых фото»): `portraits/face-profile-left.png`, `portraits/face-profile-right.png` — передаются вместе с анфасом тремя `--ref`.
**Цвет волос — холодный бежевый блонд** (её слова 2026-09-25), никогда не золотистый и не тёплый; правило зашито в генератор (`imagegen.KEEP_FACE`). Одежда — современная, не строгая классика.

## Правила

- **Мелкие кадры (343×512) крупно не ставить** — на 1080×1350 будут мутными. Нужен крупный план —
  попроси у неё оригинал.
- На трёх кадрах в правом нижнем углу видна метка ✦ генератора (`studio-*`, `window-light-red-suit`) —
  кадрируй так, чтобы угол не попадал в слайд, или закрывай его элементом вёрстки.
- Для тёмных слайдов фон убирается копией (`integrations/visuals/cutout.py`), исходник не трогать.
- Скрины размываются по умолчанию; портреты — никогда.
- **Одежду и причёску можно менять** — её прямое разрешение. Варианты делаются с этих кадров
  как с референса, **лицо и узнаваемость не меняются** (её метод «Identity Lock» из гайда
  `visual_references/интерактивные гайды/premium_ai_portrait_guide.html`). Кожу, черты, возраст
  не «улучшать».
- Генератор есть: `integrations.visuals.imagegen` (Codex по её подписке, запасной kie.ai). Образец
  внешности — `face-reference.jpg` (см. выше); сгенерированный по `katerina-portrait-2.jpg` кадр она
  назвала непохожим.
