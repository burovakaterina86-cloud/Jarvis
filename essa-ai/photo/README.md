## Правила

- **Мелкие кадры (343×512) крупно не ставить** — на 1080×1350 будут мутными. Нужен крупный план —
  попроси у неё оригинал.
- На трёх кадрах в правом нижнем углу видна метка ✦ генератора (`studio-*`, `window-light-red-suit`) —
  кадрируй так, чтобы угол не попадал в слайд, или закрывай его элементом вёрстки.
- Для тёмных слайдов фон убирается копией (`integrations/visuals/cutout.py`), исходник не трогать.
- Скрины размываются по умолчанию; портреты — никогда.
- **Одежду и причёску можно менять** — её прямое разрешение. Варианты делаются с этих кадров
  как с референса, **лицо и узнаваемость не меняются** (её метод «Identity Lock» из гайда
  `visual_references/интерактивные гайды/premium_ai_portrait_guide.html`). Кожу, черты, возраст
  не «улучшать».
- Генератора изображений в JARVIS сейчас нет — вариант с другой одеждой делается по её просьбе
  тем инструментом, которым она пользуется (её слова: «можно делать через мою подписку в GPT»).
