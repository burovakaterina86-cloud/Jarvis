# Storyboard — Нейросеть пишет не твоим голосом? (ТЕСТ)

> Art direction по `essa-ai/ESSA_PRESENTATION_STYLE.md`. Текст — дословно из `carousel.md`.
> Тест правил картинок 2026-09-25: генерация только одного кадра (её, по `face-reference.jpg`),
> всё остальное — поля вёрстки.

**Смысл серии.** Узнавание (01-02) → что именно нейросеть не знает (03) → как это ей дать (04)
→ как проверить (05) → куда идти за промптами (06).

## 01 — ОБЛОЖКА
- Мысль: безликий текст поправим. Метафора: она сама с телефоном, взгляд мимо камеры — человек,
  который это уже решил. Тип **A**. Кадр сгенерирован по её образцу (`--ref face-reference.jpg`),
  тёмный фон растворён `make_dark_fade`. Оранжевым — «твоим голосом?». Пометка: «это поправимо».

## 02 — ПОЧЕМУ ТАК
- Мысль: нейросеть не знает, как ты говоришь. Метафора: только типографика и плашка-вывод —
  пустота вместо голоса. Тип **E**. Оранжевым — «как ты говоришь».

## 03 — ЧЕГО НЕ ХВАТАЕТ
- Мысль: не хватает того, по чему тебя узнают. Метафора: четыре карточки «чего она не знает»,
  активная — «как начинаешь пост». Тип **D** (ui_cards, кодом). Оранжевым — «не знает».

## 04 — РЕШЕНИЕ
- Мысль: паспорт голоса за вечер. Метафора: цепочка из пяти шагов. Тип **C** (steps, кодом).

## 05 — ПРОВЕРКА
- Мысль: вторая голова. Метафора: поток пост → чат → список → правка. Тип **E** с потоком (flow, кодом).

## 06 — ФИНАЛ
- Мысль: всё пошагово в гайде. Цепочка сверху вниз (§19) + плашка-CTA в оранжевой обводке.
  CTA «ГОЛОС» — тестовый, не утверждён.
