# VISUAL_REFERENCES.md
## Что использовать как визуальные референсы во втором Project

STATUS: `TRANSFER INDEX`

### 1. `DESIGN.md`
Главный активный визуальный контракт: шрифты, палитра, STYLE_01 / STYLE_02_LIGHT / STYLE_02_DARK, композиция, ритм каруселей, фото, обложки, Reels.

### 2. `SKILL_carousel-instagram.md`
Production-правила сборки Instagram-каруселей 1080×1350 без изменения стратегии и CTA.

### 3. `CAROUSEL_AI_MASTERSKAYA.md`
Текстовая карта реальной 8-слайдовой карусели «Как пользоваться AI-мастерской».

### 4. `visual_references/AI_MASTERSKAYA_CAROUSEL_PREVIEW.jpg`
Визуальный preview реальной карусели. Использовать как **референс**, а не как универсальный шаблон для каждого материала.

### 5. `POST_COVERS.md`
Быстрый индекс правил обложек, вынесенный из `DESIGN.md`.

## Важно

- Файлы шрифтов не входят в пакет. Второму Project достаточно названий и правил из `DESIGN.md`.
- В активной фирменной системе используются `Roboto Condensed` и `Open Sans`.
- Упоминание `Bad Script` в `CAROUSEL_ASSETS.md` относится к конкретному сохранённому шаблону и **не делает его третьим фирменным шрифтом**. Приоритет у `DESIGN.md`.
- Отдельных достоверно идентифицированных PNG/JPG «обложек постов» как самостоятельного набора в Project Knowledge не обнаружено. Контракт обложек сохранён текстом в `DESIGN.md` и `POST_COVERS.md`; обложка реальной карусели видна в preview.
