# Профиль стиля (предварительный)

Построен 2026-10-06 по 21 её примеру рилсов (расшифровки — `examples/examples_digest.txt`, сырьё — `examples/raw/`). Скрапер не отдал цифры (просмотры, комментарии) по примерам, поэтому выводы — по содержанию, а не по охватам. Подтвердить с ней.

- **Язык:** 18 из 21 на русском, 3 на английском (английские — про ChatGPT-команды, финансовые агенты Claude, коннектор Claude + Instagram). Рынок: `ru` + `en`; английское переводим и адаптируем, русское пересобираем под неё.
- **Темы:** Claude, ChatGPT и их агенты, скиллы, коннекторы, автоматизация монтажа и контента, промпт-приёмы, контент для экспертов. Один выброс мимо ниши (исследование WSJ про успешных женщин).
- **Форматы (чаще всего):** 🛠 инструкция «как настроить» (коннектор, плагин, промпт); 🧠 «мой агент делает X» с показом процесса; 📋 список из 3–6 команд, навыков или агентов; 📰 новость/обновление и «X заменил Y»; 🧠 объяснялка простыми словами (бенчмарки); методика для экспертов («круг контента»). Реже: разбор чужого кейса.
- **Хуки:** громкое заявление («Claude только что убил…», «заменил моего видеомонтажёра»), число и список («4 команды», «6 навыков»), «этот парень запретил Claude писать код → 150 тыс. звёзд», вопрос «а что, если…», «хватит делать X», обещание «к концу видео знаете лучше 95%».
- **Призыв:** в большинстве роликов кодовое слово в комментариях («тренд», «монтаж», «инструкция», «агент», «промт», AgentOS, Wall Street). Без призыва — объяснялки и редкие разборы.
- **Длина:** обычно 28–60 с; четыре ролика 90–190 с (длинные разборы с показом экрана).
- **Тон:** разговорный, «короче», практичный; простые слова вместо терминов; «сохраняй», «покажу, как». Личных историй о жизни почти нет — только «я собрала/настроила».
- **Чего нет в примерах (такое не предлагаем):** юмор, личные драмы, чистая психология, мотивация без инструмента.
