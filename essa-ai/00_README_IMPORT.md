# 00_README_IMPORT.md
## Перенос проекта «Моя воронка» во второй ChatGPT Project

Этот пакет собран для переноса стратегии, профессионального контекста, голоса, визуальной системы и AgentOS-правил без переизобретения архитектуры.

## Что загрузить

Самый простой вариант: загрузить **`ESSA_PROJECT_KNOWLEDGE_PACK.md`** как единый knowledge-файл и отдельно `visual_references/AI_MASTERSKAYA_CAROUSEL_PREVIEW.jpg`, если нужен визуальный референс.

Если второй Project нормально работает с большим числом файлов, лучше загрузить отдельные `.md` из этого архива: так профильные SOURCE OF TRUTH проще находить и обновлять.

## Что вставить в Project Instructions

Скопировать содержимое `PROJECT_INSTRUCTIONS_FOR_SECOND_PROJECT.md`.

## Критические файлы

- `00_PROJECT_MAP.md` — иерархия источников;
- `11_DECISION_LOG.md` — принятые решения;
- `EXPERTISE.md` — фактический статус и ограничения заявлений;
- `VOICE.md` + `04_BRAND_VOICE.md` — голос;
- `DESIGN.md` — фирменный стиль, шрифты, палитра, обложки, карусели;
- `SKILL_carousel-instagram.md` — production каруселей;
- `ROUTER.md` + AgentOS-файлы — маршрутизация skills.

## Про шрифты

В пакет **не входят бинарные файлы шрифтов**. Для второго Project это не требуется: активные названия и правила использования сохранены в `DESIGN.md`.

## Про карусели и обложки

Включены:
- активный визуальный контракт `DESIGN.md`;
- skill каруселей;
- текстовая карта реальной карусели AI-Мастерской;
- assets-описание этой карусели;
- визуальный preview карусели;
- отдельный быстрый индекс `POST_COVERS.md`.

Отдельного достоверно идентифицированного набора файлов «обложки постов» в Project Knowledge нет, поэтому я не стала приписывать случайным изображениям статус фирменных обложек. Правила обложек сохранены полностью.
