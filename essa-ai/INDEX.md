# Куда смотреть — короткая карта папки

Этот файл существует ради одного: дойти до нужного материала, прочитав **два-три файла,
а не двадцать**. Маршруты взяты из `00_PROJECT_MAP.md` (раздел «Быстрая маршрутизация»),
она остаётся главной при конфликтах — но открывать её целиком ради маршрута не нужно.

## Никогда не читай целиком

Это склейки, внутри которых лежат те же файлы, что и рядом в папке. Читать их целиком —
значит потратить весь контекст хода на копию того, что и так есть.

| Файл | Размер | Что делать |
|---|---|---|
| `ESSA_PROJECT_KNOWLEDGE_PACK.md` | 377 КБ | только `Grep` по нужному слову; целиком — никогда |
| `MASTER PROMPT — …md` | 59 КБ | только `Grep`; общая картина — уже в профильных файлах |
| `AGENTOS_CHATGPT_CORE.md` | 33 КБ | только `Grep`, и только если задача про AgentOS-скиллы |
| `DESIGN.md` | 30 КБ | только когда задача про визуал, и лучше `Grep` по разделу |
| `00_PROJECT_MAP.md` | 22 КБ | целиком — только при конфликте приоритетов |

## Пары, где легко прочитать оба и заплатить дважды

- Голос: `VOICE.md` (основной) ↔ `04_BRAND_VOICE.md` (расширенный, 31 КБ) — начинай с первого.
- Аудитория: `02_AUDIENCE.md` (факты) ↔ `AUDIENCE.md` (гипотезы) — начинай с первого.
- `PROFILE.md`, `STRATEGY.md`, `PRODUCTS.md`, `ANALYTICS.md` — не данные, а указатели: одна строка,
  куда идти. Читать их дешево, но останавливаться на них нельзя.

## Если маршрута нет

Материалы в папке есть и вне этой карты: `ROLE_PACKS.md`, `CAPABILITY_MAPPING.md`, `ROUTER.md`,
`MANIFEST.md`, `SKILL_*.md`, папки `visual_references/` и `мои референсные фото/`.
