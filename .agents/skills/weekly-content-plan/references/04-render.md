# Этап 8. Оформление: одна HTML-страница

Её решение 2026-10-06: **только HTML**, дизайн как у агента («Радар»), обязательна адаптация под смартфон. Word и письмо не делаем. Файл `plan-ГГГГ-ММ-ДД.html` уходит в Telegram документом.
Генератор: `integrations/content_plan/render.py` — порт `upstream/scripts/build_plan_html.py` (оригинал 123 КБ — **только `Grep`**), YouTube и письмо убраны. Запуск: `.venv\Scripts\python.exe -m integrations.content_plan render <папка_недели>` → `plan-ГГГГ-ММ-ДД.html` рядом с JSON. Какие поля читает — в конце `03-strategy.md`.

## Жёсткие правила

- Никаких картинок, превью и скриншотов чужих рилсов и каруселей. Эмодзи, типографика, CSS-графика, инлайн-SVG. Ссылка «оригинал ↗» маленькая и вторичная.
- Прогрев в сторис в календаре один раз. В видимом тексте нет технических кодов рилсов — только «рилс @автор» или заголовок.
- Все строки проходят `html.escape`. Весь текст русский, живой, без канцелярита.
- YouTube в странице нет (блок и чипы убраны).

## Дизайн-система «Радар»

| Токен | Цвет | Где |

| text / muted | `#E8ECF2` / `#8A94A6` | текст, вторичный |
| accent | `#FFD84D` (из `profile.accent`) | рекомендуемое, цифры, кнопки |
| funnel / outlier / strong / telegram | `#FF8A4C` / `#6FD3A0` / `#9FB4FF` / `#5EC8F2` | воронки · аутлаеры · сильные · Telegram |

Glow только у рекомендуемых: `box-shadow: 0 0 0 1px <accent>55, 0 10px 40px -10px <accent>33`.
Шрифты Google Fonts: Unbounded (заголовки 600–800), Golos Text (текст), JetBrains Mono (цифры); запасные `"Segoe UI", system-ui, sans-serif` и `Consolas, monospace`. Отступы 8/16/24/48, скругления 16–20 px.
Эмодзи: 📸 Instagram · ✈️ Telegram · 🎙 подкаст · 🧲 лид-магнит · 🔥 прогрев · 🗂 карусель · 🎬 рилс; слоты 🧲 воронка · 🚀 аутлаер · 💪 сильный · ⭐ рекомендуем; метрики 💬 ▶ ⏱ ×N; форматы 🛠 📋 🧠 💡 ⚠️ 📰.

## Структура страницы

1. Hero: «Контент-план · даты», «для Катерины», 3 фразы сводки, плитки цифр отбора (в пуле → свежих → расшифровано → в плане; сумма комментариев и просмотров отобранных).
2. Неделя на ладони: 7 дней, чипы с эмодзи площадки; клик переносит к деталям.
3. 🎬 Рилсы по дням: табы, 3 карточки, рекомендуемая первая с ⭐ и glow. В карточке: чипы формата и слота, заголовок, метрики, хук, «почему рекомендуем», «📜 Сценарий» (раскрывается) и «Скопировать», пилюля кодового слова, «🎥 Для съёмки», «✨ Потенциал», чекбокс «Беру» (localStorage в try/catch, счётчик в шапке), «оригинал ↗».
4. 🗂 Карусели: слайды-квадраты 1:1 с русским текстом, горизонтальная прокрутка внутри блока, «почему в плане», кодовое слово.
5. 🔥 Прогрев в сторис: одна яркая карточка.
6. ✈️ Telegram: лид-магниты «коробками продукта», запасные, подкаст с планом.
7. 🔗 Воронка недели с реальными названиями.
8. Рилсы без речи — компактный список; ⚙️ как собрано — воронка отбора цифрами.
9. Sticky-навигация, плавный скролл, print-стили.

## Смартфон (обязательно)

- Мобильная вёрстка первична: колонки → вертикальная лента, дни недели — лента карточек, табы прокручиваются горизонтально, кнопки ≥ 44 px, шрифт текста ≥ 16 px.
- Без горизонтального скролла страницы на 360–400 px (прокручиваются только слайды каруселей внутри блока).
- `<meta name="viewport" content="width=device-width, initial-scale=1">`; безопасные отступы `env(safe-area-inset-*)`.
- Страница самодостаточная: CSS и JS внутри, внешняя только ссылка на Google Fonts; без сети — системные шрифты, вёрстка не едет.
- Файл должен открываться из Telegram (встроенный просмотр и «открыть в браузере»).

## Проверка до сдачи

Скриншоты Chrome/Edge: 1440 px и **400 px** (headless не сужает окно меньше ~500 px — телефон снимай через страницу-обёртку с iframe шириной 400 px). Посмотри глазами: наезды, пустые блоки, контраст, горизонтальный скролл. Подсчёт отрисованного: все рилсы, карусели, лид-магниты, подкаст, 1 прогрев, календарь.
