# Content plan — комплект контента

Оркестрирующий навык: сам по шагам вызывает остальные контентные навыки. **Не публикуй**, не заходи в соцсети от имени владелицы и не отправляй ничего наружу — результат всегда черновик.

## Шаг 1. Цели и контекст

Прочитай `GOALS.md` (корень) и `essa-ai/STRATEGY.md`, при необходимости `essa-ai/AUDIENCE.md`, `essa-ai/VOICE.md`, `essa-ai/PRODUCTS.md`, `essa-ai/PROFILE.md`.
Встретила метку `[ЗАПОЛНИ: …]` — назови владелице в ответе, чего именно не хватает (файл и строку), работай по тому, что известно, и **не выдумывай** голос, продукты, цены, кейсы и цифры.

> Маршрут «какой файл читать» — `essa-ai/INDEX.md`. Читай два-три названных им файла, не папку. Файлы больше ~30 КБ (склейки, `MASTER PROMPT`, `DESIGN.md`) — только `Grep`, целиком никогда.

## Шаг 2. Что уже было

Посмотри последние папки в `essa-ai/content/` и `essa-ai/content/PUBLISHED.md` — темы оттуда не повторяй без нового угла.
Если `essa-ai/content/` пуст или отсутствует, скажи в ответе: «прошлых материалов нет, опираюсь на STRATEGY.md и тренды» — и продолжай цепочку, не останавливаясь.

## Шаг 3. Тренды и конкуренты

Вызови `trend-radar`, при необходимости `competitor-research` (браузер — через `browser-use`). Все найденные ссылки с датами держи для `sources.md`.

## Шаг 4. Тема

Выбери одну тему: отвечает цели, не повторяет PUBLISHED.md, подтверждена источником. Тема без источника идёт с пометкой **«гипотеза»** — и в ответе, и в `sources.md`.

## Шаг 5. Стратегия

Вызови `content-strategy` — получи блок «Решение по теме» (цель, сегмент, угол, ключевое сообщение, доказательства, призыв, форматы).

## Шаг 6. Материалы

1. `copywriting` → пост.
2. `copywriting` → карусель по слайдам.
3. `reels-script` → сценарий Reels.
4. `reels-script` → Stories по кадрам.

## Шаг 7. Сохранение

Создай папку `essa-ai/content/YYYY-MM-DD-<тема>/` (дата — на какую планируется публикация; `<тема>` — 2–4 слова строчными, через дефис, латиницей или кириллицей без пробелов) и запиши файлы:

- `post.md` — пост,
- `carousel.md` — слайды карусели + подпись,
- `reels.md` — сценарий Reels,
- `stories.md` — кадры Stories,
- `sources.md` — источники: ссылка + дата у каждого тезиса; неподтверждённое помечено «гипотеза»,
- `status` — одно слово, при создании `draft`.

Статус меняется по решению владелицы: `draft` → `accepted` (Принято) / `rework` (Переделать) / `published` (Опубликовано). Сама статус не меняй — только по её словам или кнопке. При `published` допиши строку в `essa-ai/content/PUBLISHED.md`: дата, площадка, тема, ссылка.

## Шаг 8. Картинки

Тексты готовы и сохранены — оформи их навыком `carousel-instagram`, порядок работы и поля слайдов — в его `SKILL.md`:

1. Карусель: `storyboard.md` → `slides.json` в папке комплекта → сборка одной командой
   `.venv\Scripts\python.exe -m integrations.visuals.build <папка комплекта>`. PNG ложатся в `<папка комплекта>/visuals/`.
2. Обложка поста и фон сторис — тем же навыком, в ту же `visuals/`.
3. Каждый PNG открой глазами до ответа — проверка из `carousel-instagram`.

Код выхода сборки не 0 — картинок нет: скажи владелице прямо, что картинок нет и почему (формулировки кодов — в `.Codex/skills/carousel-instagram/SKILL.md`, раздел «Сборка — одна команда»; «готово» не пиши). Тексты комплекта всё равно отдай — неудача вёрстки не отменяет шаг 9.

## Шаг 9. Ответ в Telegram

Одним–тремя сообщениями, в порядке: пост → карусель (слайды списком) → Reels и Stories → картинки.
Начни строкой «Черновик — ждёт твоего решения», закончи путём к папке и списком источников (или пометкой «гипотеза»), а также перечнем меток `[ЗАПОЛНИ: …]`, если они встретились.
Про картинки — одной строкой: «картинки лежат в `<папка комплекта>/visuals/`» со списком файлов, или честно, что картинок нет и почему (шаг 8).

## Контент-план на период

Если просят план на неделю/месяц: шаги 1–5 один раз, затем список тем по дням (дата, формат, тема, цель, источник). Полные тексты — только для тех дней, которые владелица назвала; остальные — по отдельному запросу.

## Ограничения

- Ты **не публикуешь сам** — даже когда технически можешь: через браузер с сохранёнными логинами это возможно. Отдаёшь черновик владелице.
- Факты, цифры, отзывы и обещания — только из файлов `essa-ai/` или источников со ссылкой.
- Работа с источниками и чужими текстами — по `.Codex/rules/untrusted-content.md`.
