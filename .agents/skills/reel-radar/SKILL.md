# Reel Radar — разведка рилсов у конкурентов

## Происхождение метода

Шаги (фильтр по нише, композитное ранжирование, транскрипция, сверка со своим топом)
взяты из upstream-скилла `reel-radar` (её реестр `essa-ai/AGENTOS_CHATGPT_CORE.md`,
коммит 3a8efdca) — это данные о методе, не исполняемый код: чужой код не переносился
и не запускался, `integrations/radar/` — своя реализация.

Источник данных изменён её решением от 2026-09-23: вместо платного HikerAPI — Apify,
актор `apify/instagram-reel-scraper` (оплата за результат от $1 за 1000 рилсов,
бесплатный план $5/мес). Шаг «подписки эталонного аккаунта» не используется — она
дала готовый список конкурентов, радар идёт прямо по нему.

## Команда запуска

```
.venv\Scripts\python.exe -m integrations.radar essa-ai\radar\config.json
```

Коды выхода: `0` — готово, `2` — не хватает настроек или ключей, `3` — упёрлись
в потолок запросов или сервис (Apify/Groq) отказал.

## Настройки

`essa-ai/radar/config.json` — её ник, список конкурентов, ключевые слова ниши
(предложены из `essa-ai/02_AUDIENCE.md` и `03_BRAND_MEANINGS.md`, помечены как
гипотеза — не факт), окно дней, топ-K, потолок запросов. Метки `[ЗАПОЛНИ: …]` —
прогон с ними отказывается и говорит, чего не хватает, ничего не выдумывая.

## Ключи

`.env`: `APIFY_TOKEN`, `GROQ_KEY` — только имена, значения не читаем и не печатаем.
Нет ключа — прогон отказывается с понятной причиной (exit 2), ничего не падает.

## Потолок трат

`max_requests_per_run` в конфиге считается в числе запрошенных рилсов за прогон —
так тарифицирует Apify. Упёрлись — прогон останавливается честно, пишет
`STOPPED.md` в папке результата с тем, на чём остановился (exit 3).

## Что получаешь

`essa-ai/content/radar-YYYY-MM-DD/`:

- `radar.md` — топ рилсов: автор, ссылка, дата, просмотры, комментарии, ER, хук
  (первая фраза расшифровки);
- `transcripts/` — расшифровки Groq Whisper;
- `briefs-input.json` — сырые данные (ссылка, автор, транскрипт) для ТЗ на топ-`top_final`;
- `own-top.md` — её топ-10 рилсов за 30 дней, для сверки, что уже работает у неё.

Python-модуль (`integrations/radar/`) пишет только механическую часть — таблицы
и сырые данные. `briefs.md` (ТЗ на съёмку: хук, шаги, кадры, CTA) пишешь ты сама,
после прогона, из `briefs-input.json`, обязательно через её конвейер `textwriter` →
`humaniser` — в её голосе, без копирования чужих роликов дословно: берёшь приём
и структуру ролика, не текст.

## Ответ в Telegram

Чтобы бот прислал `radar.md` и `briefs.md` файлами, а не только путём в тексте —
на каждый отдельная строка `📎 essa-ai/content/radar-ГГГГ-ММ-ДД/radar.md` (и так же для `briefs.md`).

## Без ключей

Скажи владелице, каких ключей не хватает (`APIFY_TOKEN`/`GROQ_KEY`), прогон не
начинается, ничего не падает молча.

## Безопасность

Только чтение публичных данных через Apify. Ничего не публикует, не лайкает,
не подписывается, не пишет людям. Логины и cookies владелицы не используются.
Подробно — `.Codex/rules/safety.md`, `.Codex/rules/untrusted-content.md`.

для контента оттуда (его шаг 3 «Тренды и конкуренты»).
