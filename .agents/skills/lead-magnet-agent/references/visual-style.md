# Паспорт визуального стиля · ESSA.AI

Источник: карусель ESSA.AI от 22.09.2026 (9 слайдов). Паспорт переложен под PDF-лидмагнит формата A4, который читают с телефона.

## Характер

Редакционный стиль на чередовании тёмных и светлых страниц: спокойный, собранный, с ритмом «вечер - день». Тёмные страницы задают вес и паузу, светлые дают легко читать и работать с инструкциями. Крупная плотная типографика говорит уверенно, а рукописные пометки оранжевым добавляют живого человека рядом с системой. Ощущение: тебе не продают, а раскладывают по полочкам.

## Палитра

### Тёмные страницы

| Роль | Цвет | Где |
|---|---|---|
| Фон страницы | `#0B0B0F` | основной фон всех страниц |
| Фон с глубиной | градиент `#0B0B0F` → `#15121F` (фиолетовый отсвет в одном углу) | обложка, разделители глав |
| Фон карточки | `#1A1922` | карточки, блоки, плашки |
| Рамка карточки | `#2E2C3A`, 1 px | обычные карточки |
| Основной текст | `#F2F1F5` | заголовки и основной текст |
| Второстепенный текст | `#9A98A6` | подписи, пояснения, номера страниц |
| Акцент 1 (оранжевый) | `#F4955A` | ключевое слово в заголовке, номера, стрелки, рамка выделенной карточки, рукописные пометки |
| Акцент 2 (лаванда) | `#B79CF5` | второй уровень выделения: «что важно запомнить», человеческие решения, ссылки |

### Светлые страницы

| Роль | Цвет | Где |
|---|---|---|
| Фон страницы | `#F4F2F7` | светлые страницы |
| Фон карточки | `#FFFFFF` | карточки, блоки, плашки |
| Рамка карточки | `#E2DEEA`, 1 px | обычные карточки |
| Основной текст | `#16141C` | заголовки и основной текст |
| Второстепенный текст | `#6E6B7B` | подписи, пояснения, номера страниц |
| Акцент 1 (оранжевый, темнее для контраста) | `#E27A3A` | те же роли, что на тёмных |
| Акцент 2 (лаванда, темнее для контраста) | `#7B5CD6` | те же роли, что на тёмных |
| Фон промпта | `#16141C` с текстом `#F2F1F5` | блок промпта остаётся тёмным и на светлой странице |

Правило пропорций на тёмной странице: 85-90% тёмного, 5-10% светлого текста, оранжевый - точечно. На светлой странице то же самое наоборот: фон и белые карточки, тёмный текст, оранжевый точечно. Лаванда появляется не на каждой странице, а там, где нужно второе, отличное от оранжевого, выделение.

## Типографика

- **Заголовки:** Oswald SemiBold / Bold, ВЕРХНИЙ РЕГИСТР, плотный межстрочный (1.0-1.1). Одно-два ключевых слова заголовка - оранжевым, отдельной строкой.
- **Основной текст:** Open Sans Regular, межстрочный 1.5.
- **Рукописные пометки:** Caveat, оранжевый, с небольшим наклоном (-3…-5°), под ними тонкая оранжевая дуга-подчёркивание.
- **Служебные надписи** (номер главы, «ПРИМЕР», «ФОРМУЛА»): Open Sans SemiBold, верхний регистр, разрядка +8-10%, мелко.
- Все три шрифта есть в Google Fonts и поддерживают кириллицу.

Кегль под A4 для чтения с телефона:

| Элемент | Размер |
|---|---|
| Заголовок обложки | 56-72 pt |
| Заголовок главы | 34-40 pt |
| Подзаголовок | 22-24 pt |
| Основной текст | 15-16 pt |
| Текст в карточке / промпт | 14-15 pt |
| Рукописная пометка | 22-26 pt |
| Служебные надписи | 11-12 pt (единственное, что может быть мельче 14) |

## Приёмы оформления

- **Верхняя служебная строка на каждой странице:** слева номер «03 / 12» (номер оранжевым), тонкая горизонтальная линия, справа название раздела капсом серым.
- **Нижняя строка:** слева `@studio_essa_ai` серым, справа оранжевая стрелка →.
- **Карточки:** скругление 14-16 px, фон `#1A1922`, тонкая рамка. Главная карточка в ряду выделяется оранжевой рамкой, остальные остаются нейтральными.
- **Номера в карточках:** маленькие оранжевые «01», «02» в левом верхнем углу.
- **Блок «Пример» и промпты:** карточка с толстой оранжевой полосой слева (4 px), над текстом служебная надпись «ПРИМЕР» / «ПРОМПТ» оранжевым. Промпты набираются моноширинным шрифтом (JetBrains Mono) на фоне чуть темнее карточки, чтобы их было легко копировать.
- **Схемы и процессы:** цепочки карточек с тонкими оранжевыми стрелками, рисуются кодом.
- **Сравнения:** две колонки, одна нейтральная, вторая с лавандовой рамкой и лавандовыми пунктами.
- **Иконки:** тонкие линейные (Lucide / Phosphor Thin), оранжевые, внутри маленькой квадратной карточки.
- **Фото автора:** тёплая направленная подсветка на тёмном фоне, фото растворяется в фон без рамки. Только на обложке и в финале.
- **Рукописная пометка:** одна на страницу максимум, в свободном нижнем углу - короткий вывод человеческими словами.
- **Фоновая деталь:** одна-две тонкие диагональные линии и мягкий фиолетовый отсвет. Едва заметно.

## Чередование фонов

- Обложка и финальная страница со ссылкой - тёмные.
- Внутри тёмные и светлые страницы чередуются по смысловым блокам: подряд не больше двух страниц одного фона.
- Тёмный фон - для открытия главы, ключевого момента, большой схемы, формулы, крупного визуала.
- Светлый фон - для пошаговых инструкций, списков, скриншотов и страниц, где много читать.
- Служебная строка, карточки, стрелки и пометки на обоих фонах устроены одинаково, меняются только цвета по палитре. Так документ выглядит цельным, а не собранным из двух.

## Воздух и плотность

Поля страницы не меньше 18 мм. Между смысловыми блоками большой вертикальный отступ, заголовок отделён от текста заметно сильнее, чем абзацы друг от друга. Одна страница - одна мысль: лучше лишняя страница, чем две мысли в тесноте. Крупный визуал (схема, фото, формула) может занимать полстраницы и больше.

## Чего в этом стиле не бывает

- Больше двух страниц подряд одного фона.
- Серых «средних» фонов между тёмным и светлым.
- Больше двух акцентных цветов, радужных градиентов, неона.
- Оранжевых заливок больших площадей: оранжевый - только текст, линии, рамки.
- Жирных толстых рамок и теней-«подушек».
- Засечных и декоративных шрифтов, кроме рукописного Caveat в пометках.
- Больше одной рукописной пометки на странице.
- Стоковых фото людей и 3D-иконок.
- Эмодзи в оформлении.
- Текста мельче 14 pt (кроме служебных надписей).
- Текста, прижатого к краям, и страниц без воздуха.
