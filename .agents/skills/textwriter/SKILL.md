# Textwriter — первый языковой проход

Источник истины — `essa-ai/SKILL_textwriter.md`. Правила ниже перенесены дословно;
расхождение → верен её файл, а этот навык надо поправить.

## Activation

Использовать ОБЯЗАТЕЛЬНО для публичных текстов Катерины:
- пост;
- Telegram-пост;
- Instagram/VK caption;
- продающий текст;
- лонгрид;
- текст карусели после определения функции слайдов;
- публичный сценарный текст после профильного skill, если он предназначен для публикации.

Пайплайн:
`content brief → textwriter → humaniser → VOICE/preflight → final`

## Роль в Project

`textwriter` — не источник стратегии и не источник фактов.

Он отвечает только за языковое исполнение уже определённого контент-брифа.

Приоритет:
1. текущий запрос Катерины;
2. `11_DECISION_LOG.md`;
3. профильные SOURCE OF TRUTH;
4. `VOICE.md` + `04_BRAND_VOICE.md`;
5. `07_CONTENT_RULES.md`;
6. этот skill;
7. upstream-примеры skill.

## Обязательные Project overrides

Если upstream `textwriter` конфликтует с Project, Project всегда выше.

НЕЛЬЗЯ:
- придумывать личные сцены, даты, места, воспоминания, внутренние монологи, чувства или диалоги;
- придумывать цифры, клиентов, результаты, провалы, доходы, отзывы или доказательства;
- добавлять мат: `VOICE.md` его запрещает;
- заменять утверждённый CTA;
- менять FUNNEL_STAGE, FUNCTION, BELIEF_BEFORE, BELIEF_AFTER, MAIN_IDEA, PROOF или NEXT_STEP;
- менять статус FACT / DECISION / HYPOTHESIS / GOAL / TEST RESULT;
- превращать собственный прототип в клиентский кейс;
- усиливать обещания ради более сильного hook;
- удалять утверждённую брендовую формулу только потому, что она похожа на общий копирайтинговый паттерн;
- запрещать списки, если формат материала — инструкция, чек-лист, карусель или навигационный пост.

Разрешена конкретика ТОЛЬКО из подтверждённых Project-файлов или прямого сообщения Катерины.

Кинематографичная сцена допустима ТОЛЬКО если Катерина реально предоставила эту сцену как факт/материал.

## Production pass

Получив утверждённый контент-бриф:

1. Сохрани одну главную мысль и один психологический переход.
2. Сохрани CTA и proof-status.
3. Напиши текст по `VOICE.md`.
4. Используй анти-ИИ правила upstream `textwriter` как языковой фильтр, а не как стратегию.
5. Проверь, что живость не создана выдуманными деталями.
6. Перед выдачей передай текст в обязательный следующий pass: `humaniser`.

В обычном production-режиме не показывай пользователю служебный аудит. Покажи только финальный текст после всей цепочки, если Катерина отдельно не попросила разбор.
