## 1. Размытие по выбору (G23)

Её слова: «если скины реальные, можно не делать размытие».

Сейчас размытие обязательно и данными не отключается — так было нарочно, по её прежнему решению.
Теперь она его смягчает:

- Размытие отключается **для каждого скрина отдельно**: элемент `screens` (и одиночный скриншот)
  принимает `"blur": false`.
- **По умолчанию размытие включено.** Выключается только явным `"blur": false`.
- В «7 признаках» выключи размытие на её настоящих экранах: домашний экран телефона на 03,
  экран ноутбука на 07.
- Тест: без поля — размыто; с `"blur": false` — не размыто; портрет не размывается никогда.
- В навыке одной строкой: скрин владелицы размывается по умолчанию; не размывать — только если
  она сказала, и перед этим предупредить её, что станет читаемо.

## 2. Иконки в блоках схемы по центру (G24)

Слайд 06 — схема «сценарий → текст → оформление → монтаж → публикация». Иконка и подпись в каждом
блоке — по центру блока, по горизонтали и вертикали.

## 3. Схема в два ряда (G25)

Её слова: «плашки можно сделать с переносом чтобы они не смотрелись такими плоскими три сверху
и две снизу между ними стрелки».

- Пять блоков: **три в верхнем ряду, два в нижнем**.
- Стрелки между блоками в ряду и **стрелка-переход с конца верхнего ряда в начало нижнего**, чтобы
  порядок читался однозначно.
- Нижний ряд центрируется под верхним.
- Стрелки оранжевые, как сейчас. Блоки остаются одинаковыми и компактными (её §8 TYPE C).
- Правило общее, не только для этого слайда: цепочка длиннее четырёх блоков переносится в два ряда.

## Не ломать

Всё принятое: тёмный фон по умолчанию и чередование по слову, типы A–E, UI-хаос, корпус устройства,
портреты, пометки внутри полей, пустота меньше пятой части холста, сборка с перехваченным выводом,
коды выхода 0/2/3, обложка и сторис из `slides.json`.

## Критерии готовности

- На 03 и 07 скрины не размыты; во всех остальных случаях без поля — размыты.
- На 06 пять блоков в два ряда 3+2 со стрелками, иконки и подписи по центру блоков.
- Полный прогон зелёный, тестов больше, чем было (сейчас 563), включая тест зеркал.
