# Спецификация — стиль Катерины и картинки

Вторая сборка поверх работающего JARVIS. Ничего из первой не переделывается.

## Задача

**Её прямой вопрос — «контент он пишет только текст? но не делает, ни карусели,
ни фоны для сторис, ни обложки для постов?» — ответ: да, правильно поняла.** Сейчас только
текст. Эта сборка закрывает все три пункта списка.

Агент пишет текст, но (1) не прогоняет его через её собственный конвейер очистки,
(2) не делает картинок вообще, (3) не применяет шесть её AgentOS-скиллов, которые
лежат в `essa-ai/` документами.

## Решение

Три независимых куска и один маленький заслон.

1. **Конвейер текста** — навыки `textwriter` и `humaniser` переносятся в `.claude/skills/`
   и становятся обязательным проходом для любого публичного текста.
2. **Картинки** — вёрстка слайда в HTML по её дизайн-системе, снимок браузером в PNG.
3. **Перенос остальных скиллов** — `carousel-instagram` (ведёт картинки), `reels`,
   `content-engine`, `present` как навыки.
4. **Заслон 100 КБ** на чтение больших файлов.

## Истории

### История 1 — конвейер текста (S05, S06)

Её контракт (`SKILL_humaniser.md`, дословно): `content brief → textwriter → humaniser → VOICE/preflight → final`.

- `textwriter` — первый языковой проход: пишет по брифу материала.
- `humaniser` — второй, обязательный: чистит нейросетевые клише.
- **Что humaniser менять не имеет права** (её же список): `FUNNEL_STAGE`, `FUNCTION`,
  `BELIEF_BEFORE → BELIEF_AFTER`, `MAIN_IDEA`, `CTA`. Смысл и факты неприкосновенны.
- Приоритет источников при конфликте — её порядок: текущий запрос → `11_DECISION_LOG.md`
  → профильный источник → `VOICE.md` + `04_BRAND_VOICE.md` → `07_CONTENT_RULES.md` → черновик.
- Навык `copywriting` и помощник `copywriter` после этого не пишут «в один проход»:
  они вызывают конвейер. Если проход почему-то не выполнен, текст всё равно доходит до
  владелицы — но с честной пометкой, что очистку он не прошёл. Она просила прогон,
  а не запрет на выдачу.
- Видимый признак прохода: в комплекте рядом с текстом лежит строка, что проход выполнен.

### История 2 — картинки (S07, S08, E02)

Картиночной модели у агента нет и не будет. Рисуем вёрсткой:

1. Навык строит HTML-страницу слайда по её дизайн-системе.
2. Браузер (Playwright, уже подключён) открывает файл и снимает кадр нужного размера.
3. PNG ложится в папку комплекта рядом с текстами.

**Источники стиля — только её файлы, ничего не выдумывается. Все три пункта её списка
закрыты своим источником:**

| Что рисуем | Правила берём из | Размер |
|---|---|---|
| карусель | `SKILL_carousel-instagram.md` + `DESIGN.md` §«Instagram carousel» | 1080×1350 |
| обложка поста | `POST_COVERS.md` **и** `visual_references/обложки на посты/SKILL_cover-post-katerina_SHORT.md` | 1080×1350 |
| фон сторис | `DESIGN.md` §18 «REELS — VISUAL SYSTEM»: крупный текст, одно сообщение на сцену, один key phrase | 1080×1920 |

Общая основа для всех трёх — `DESIGN.md`: 12 цветов с кодами, Roboto Condensed Bold для
заголовков, Open Sans Regular для текста, Open Sans SemiBold для подзаголовков.

**У неё уже есть готовый код вёрстки** — `visual_references/design-code-studio_essa_ai-v1.html`,
44 КБ. Его смотрят первым и берут за основу, а не пишут разметку с нуля. Рядом —
папки `карусель стиль 1`, `карусель стиль 2`, `обложки на посты` с её примерами,
`CAROUSEL_ASSETS.md` и `VISUAL_REFERENCES.md`.

**Размеры — её же:** карусель и обложка `1080×1350`, сторис `1080×1920`.

**Шрифты.** На машине не установлены; берутся с Google Fonts при рендере — те же самые
файлы. Нет сети → рендер не молчит, а говорит, что шрифт подменён, и называет чем.

Третий фирменный шрифт не вводится — её прямое ограничение в `POST_COVERS.md`.

### История 3 — перенос её скиллов (S02, S03, E01)

Шесть файлов `essa-ai/SKILL_*.md` — это адаптеры для ChatGPT-проекта. Для JARVIS навык
это папка `.claude/skills/<имя>/SKILL.md`. Переносятся четыре, нужные выбранным ею пунктам: `textwriter`, `humaniser`,
`carousel-instagram`, `reels`. Плюс `content-engine` — он оркестрирует остальные.
**`present` (презентации) не переносится: про презентации в задаче нет ни слова.**

- Смысл, правила и запреты берутся из её файлов **дословно**; переписывать нельзя.
- Исходный файл в `essa-ai/` остаётся на месте и остаётся источником истины.
- Существующие навыки JARVIS (`copywriting`, `reels-script`, `content-plan`) не дублируются:
  где её скилл строже, он главнее, и навык JARVIS его вызывает.
- `create-skill` (S03) дополняется форматом её адаптеров: чтобы новый навык, который агент
  создаст сам, ложился в тот же вид, а не в свой.
- Включение любого нового навыка — по-прежнему кнопкой владелицы, через `drafts/`.

### История 4 — заслон 100 КБ (S09)

Чтение файла больше 100 КБ требует её кнопки. Порог выбран так, чтобы ложных
срабатываний не было: самый большой живой файл — 59 КБ.

- Ограничение на чтение, не на поиск: `Grep` по большому файлу проходит свободно.
- Отказ объясняет, что файл велик, и предлагает `Grep` вместо чтения.

## Вне рамок этой сборки

| Что | Почему |
|---|---|
| лид-магниты (S10) | владелица не выбрала в «с чего начать» |
| рилс-радар по конкурентам (S11) | то же |
| контент по залетевшим рилсам (S12) | то же; зависит от S11 |
| навык `present` (презентации) | в задаче о презентациях не сказано; файл остаётся в `essa-ai/`, перенести можно в любой момент |
| генерация картинок нейросетью | вёрстка точнее и повторяемее; её стиль задан кодами цветов |

## Решения, принятые за неё

| Решение | Почему |
|---|---|
| шрифты с Google Fonts, а не скачиваются в проект | те же файлы, ничего не тащим в репозиторий; при отсутствии сети рендер честно скажет о подмене |
| картинки рисуются вёрсткой, а не генератором | её дизайн-система задана точными кодами цветов и шрифтами — вёрстка воспроизводит их точно, генератор «похоже» |
| одна точка снимка `render_image(...)` и картинки кладутся в ту же папку комплекта | техническое решение: иначе каждый навык заведёт свой способ, и стиль разъедется |
| стиль применяется пока к текстам и картинкам, не ко всем каналам сразу | она просила «в моём стиле всё», но Reels-сценарии, подписи и сторис-тексты идут через тот же конвейер текста — отдельной работы по ним в этой сборке нет |

## Границы и швы

- `render_image(html_path, out_png, width, height)` — единственная точка снимка.
- Папка комплекта не меняет формат: картинки добавляются файлами рядом с текстами.
- Проход конвейера — функция, а не уговор: навык `copywriting` вызывает её.
