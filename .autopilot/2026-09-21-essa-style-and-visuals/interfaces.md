# Что уже построено

Читается каждым исполнителем до начала работы. Не изобретай заново то, что здесь есть.

## Проект, каким его застал этот заход

JARVIS — личный агент владелицы поверх Claude Code, общение через Telegram. Первая
сборка сдана: мост к Claude Code, Guard и подтверждения кнопкой, память, восемь навыков,
шесть помощников, браузер через Playwright MCP. Полное описание — `AGENTS.md` в корне.

- Тесты: `.venv\Scripts\python.exe -m pytest -q` (сейчас 314 passed), один файл —
  `.venv\Scripts\python.exe -m pytest -q tests\test_<имя>.py`.
- Питон только из `.venv`. Зависимости — `requirements.txt`; не хватает пакета —
  верни `BLOCKED` с названием, сам не ставь.
- Навык = папка `.claude/skills/<имя>/SKILL.md` с frontmatter `name` и `description`.
  Формат проверяется тестом `tests/test_skills_format.py` — посмотри его до того, как писать.
- Помощник = файл `.claude/agents/<имя>.md` с frontmatter `name`, `description`, `tools`, `model`.
- Защита: `.claude/hooks/guard.py` + `runtime/policy.yaml`, уровни READ / WRITE / EXTERNAL / MONEY.
  Тесты защиты — `tests/test_guard.py`.
- Браузер: MCP `playwright` в `.mcp.json`, профиль `state/browser-profile`,
  среди инструментов есть `mcp__playwright__browser_take_screenshot` (уже разрешён политикой).
- Папка комплекта контента: `essa-ai/content/YYYY-MM-DD-<тема>/` с `post.md`,
  `carousel.md`, `reels.md`, `stories.md`, `sources.md`, `status`.
- Маршрут по материалам владелицы — `essa-ai/INDEX.md`. Файлы больше ~30 КБ целиком не читать.

## Общие правила этого захода

- Код и комментарии по-русски, как в соседних модулях.
- Файлы владелицы в `essa-ai/` — источник истины. Читать можно всё; **менять нельзя ничего**,
  кроме того, что твой таск называет прямо.
- Фактов о владелице не выдумывать: цвета, шрифты, размеры, тексты — только из её файлов.
- Ничего не публиковать и не отправлять.

## Границы, решённые в спецификации

- `render_image(html_path, out_png, width, height)` — единственная точка снимка страницы.
- Проход текста — вызываемая функция навыка, а не уговор в инструкции.
- Размеры: карусель и обложка `1080×1350`, сторис `1080×1920` (из её файлов).
