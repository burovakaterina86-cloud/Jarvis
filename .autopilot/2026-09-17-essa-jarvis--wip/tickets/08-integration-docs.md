## Что должно заработать

Всё собрано в одну работающую систему, и владелица знает, как её запустить. Офлайн-сквозной тест: фейковый Telegram-апдейт → task_router → bridge на фейковом claude, который вызывает инструмент → реальный Guard → Approvals API → фейковое нажатие → результат в фейковый чат; плюс проверка, что нет `dangerously-skip-permissions`, `check_context_size.py` зелёный, весь `pytest` зелёный. Реальный дымовой прогон на машине: `claude -p` через `run_turn` с настоящими `runtime/jarvis-settings.json` и хуками — ход «прочитай essa-ai/PROFILE.md и перечисли, чего не хватает» проходит, попытка «прочитай .env» блокируется Guard (зафиксировать в отчёте). `docs/REFERENCE.md` — флаги CLI, формат событий, policy.yaml, команды бота, как добавить правило. `docs/SETUP.md` — пошагово для владелицы: создать бота у @BotFather, вписать токен и ID в `.env` самой, `claude` залогинен, `start.bat`, `/whoami`, вход на сайты `/browser_login`, автозапуск (команда регистрации), чек-лист приёмки из docs/MVP.md.
