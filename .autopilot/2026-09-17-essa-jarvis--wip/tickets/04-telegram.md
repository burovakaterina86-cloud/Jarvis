## Что должно заработать

С телефона можно писать и наговаривать задачи боту, видеть ход работы и нажимать «Подтвердить». `python -m integrations.telegram` (python-telegram-bot, polling): загрузка `.env` (без вывода значений), allow-list из `TELEGRAM_OWNER_ID` — чужие апдейты молча в лог, пустой ID → бот стартует в режиме настройки и отвечает только на `/whoami` (показывает ID отправителя) и больше ни на что. Текст → `task_router.submit` → `run_turn`; одно статус-сообщение, редактируемое не чаще раза в 3 с (этап, инструмент, время); ответ разбит по 4096 без разрыва ``` блоков, очень длинный — документом. Голос → `voice.transcribe` (faster-whisper, модель из `JARVIS_WHISPER_MODEL`, по умолчанию `small`, int8, `language="ru"`, `vad_filter=True`; ogg декодируется через PyAV, встроенный в faster-whisper) → «🎙 распознал: …» → в агента; неудача → вежливый отказ. Фото/файлы → `inbox/YYYY-MM-DD/<очищенное имя>` → путь в промпт. Команды: `/new`, `/stop`, `/status`, `/browser_login <url>` (запускает `integrations/browser/login.py`, если файл есть). Approvals: подписка на `approvals.on_request` → сообщение с текстом summary и кнопками «Подтвердить»/«Отклонить» → `resolve`. Кнопки «Принято / Переделать / Опубликовано» под контент-комплектом (callback пишет `status` и строку в `essa-ai/content/PUBLISHED.md` при «Опубликовано»). При старте: поднять Approvals API, сообщение владелице «JARVIS на связи». `start.bat` дописать до рабочего запуска; `scripts/install_autostart.ps1` — регистрация задачи в Планировщике (не запускать автоматически: регистрацию делает владелица сама, в отчёте — команда).
