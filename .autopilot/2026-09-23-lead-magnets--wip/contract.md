# Лид-магниты — общий контракт двух частей

Её слова: «еще мне нужно чтобы он мог делать лид-магниты» (бриф 2026-09-21), «давай лид-магниты» (2026-09-23).
Формат выдачи — её выбор кнопкой: **«PDF в моём стиле»**.
Первый лид-магнит — её главный по стратегии: **«AI-аудит контент-рутины»**
(`essa-ai/04_PRODUCTS_AND_AI_WORKSHOP.md` §3–4, `essa-ai/05_FUNNEL.md` §5, CTA «Напиши АУДИТ»).

## Формат данных — `lead-magnet.json` в папке лид-магнита

Текст пишет одна часть, вёрстка читает этот файл. Поля:

```json
{
  "title": "заголовок",
  "subtitle": "подзаголовок",
  "author": "Катерина Бурова · ESSA.AI",
  "intro": ["абзац", "абзац"],
  "sections": [
    {
      "heading": "заголовок раздела",
      "body": ["абзац", "абзац"],
      "table": {"columns": ["Процесс", "Часов в неделю", "Раздражение 1–5", "Итог"],
                "rows": [["Монтаж", "", "", ""]]},
      "checklist": ["пункт", "пункт"],
      "note": "короткий нюанс от неё, выделяется плашкой",
      "handwritten": "рукописная пометка 2–3 слова, необязательно"
    }
  ],
  "cta": {"text": "мягкое приглашение на следующий шаг", "keyword": "АУДИТ"}
}
```

`table`, `checklist`, `note`, `handwritten` — необязательны. Пустые клетки таблицы — это поля
для заполнения читателем, вёрстка рисует их как место для записи.

## Где что лежит

- `essa-ai/content/lead-magnets/ai-audit/lead-magnet.json` — данные (пишет часть «текст»);
- `essa-ai/content/lead-magnets/ai-audit/ai-audit.pdf` — результат (делает часть «вёрстка» одной командой).

## 2026-09-23 — поправка владелицы: стиль и формат

Она посмотрела PDF и спросила: «а откуда ты взял этот стиль? разве это мой стиль?» — и была права.
PDF был свёрстан системой каруселей (`ESSA_PRESENTATION_STYLE.md`), а для гайдов у неё свой стиль:
`essa-ai/visual_references/интерактивные гайды/` (два её гайда) и `DESIGN.md` §19 «PRESENTATIONS / HTML GUIDES».
На вопрос о формате ответила кнопкой: **«Интерактивный HTML-гайд, как мои»**.

### Приёмы из её гайдов

Тёмно-зелёный первый экран с плашкой-«таблеткой» («ESSA.AI · …»), крупный жирный заголовок строчными
с оранжевым смысловым словом, подзаголовок, две кнопки (оранжевая залитая и контурная); липкая
навигация-«таблетка» по разделам; кремовые разделы с меткой «01 · …» оранжевым капсом над заголовком;
белые скруглённые карточки с мягкой тенью и значком в цветном квадрате; нумерованные шаги кружками,
зелёный и оранжевый попеременно; процесс карточками со стрелками-кружками между ними.
