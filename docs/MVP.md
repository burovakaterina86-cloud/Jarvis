# ESSA-JARVIS — первая рабочая версия (MVP)

> Для кого: владелица ESSA.AI и разработчик.
> Что входит: этапы V0.1a–V0.6-lite. Общая архитектура — в `docs/ARCHITECTURE.md`.
> Статус: **дизайн, ждёт подтверждения.**

---

## 1. Что умеет

Все сценарии — с телефона, в Telegram, текстом или голосом.

### Общение

| Вы пишете / делаете | JARVIS делает |
|---|---|
| «Привет» | отвечает в том же чате; думает Claude Code по вашей подписке |
| Наговариваете голосовое | показывает «🎙 распознал: …» и выполняет. Если не разобрал — «не разобрал голосовое — повтори или напиши текстом» |
| Присылаете фото или файл | сохраняет в `inbox/<дата>/` и работает с ним |
| Пишете, пока он занят | «принял, возьму после текущей задачи (в очереди: N)» |
| `/stop` | останавливает текущую задачу, статус «остановлено» |
| `/new` | начинает разговор заново |
| — | пока работает, обновляет одно сообщение-статус: этап, инструмент, время |
| — | длинный ответ приходит целиком: разбит на части без разрыва кода, большой — файлом |
| — | если закончился лимит: «лимит подписки, продолжу в HH:MM»; если слетел вход: «нужно заново войти в Claude на компьютере» |
| Кто-то другой пишет боту | тишина; попытка записывается в лог |

### ESSA.AI

| Вы пишете | JARVIS делает |
|---|---|
| «Что ты знаешь про ESSA?» | читает профиль в `essa-ai/` и перечисляет, чего не хватает |
| — | файлы `essa-ai/` читает только когда задача про ESSA |
| — | если профиль не заполнен, говорит, чего не хватает, и не выдумывает |

### Контент

| Вы пишете | JARVIS делает |
|---|---|
| «Сделай контент для ESSA на завтра» | цели → прошлые материалы → тренды и конкуренты в браузере → тема → стратегия → **пост + карусель + Reels-сценарий + Stories** одним-тремя сообщениями |
| — | сохраняет в `essa-ai/content/ГГГГ-ММ-ДД-<тема>/`: `post.md`, `carousel.md`, `reels.md`, `stories.md`, `sources.md` |
| — | в `sources.md` ссылки и даты; тема без источника помечена «гипотеза» |
| — | если прошлых материалов нет: «прошлых материалов нет, опираюсь на STRATEGY.md и тренды» |
| Кнопки «Принято» / «Переделать» / «Опубликовано» | записывает статус; **сам ничего не публикует** |
| «Я выложила пост про X» или кнопка «Опубликовано» | добавляет строку в `PUBLISHED.md` и дальше не повторяет тему |

### Поручения в браузере

| Вы пишете | JARVIS делает |
|---|---|
| «Положи в корзину Самоката молоко и хлеб» | открывает сайт в своём браузере, собирает корзину, присылает скриншот и сумму. Оформление — только после «Подтвердить» с суммой и составом |
| «Подбери билеты в Москву на пятницу» | три варианта: цена, время, пересадки, ссылка, скриншот → вы выбираете кнопкой → бронирование только после «Подтвердить» с суммой, пассажиром и рейсом |
| «Ответь на комментарии в Instagram» | читает комментарии, готовит ответы списком; отправка — после «Подтвердить» |
| «Найди / сравни / собери …» | выполняет; всё внешнее — через те же уровни безопасности |
| — | если сайт просит капчу, вход или SMS: «нужен ты: <что>» — обходить не пытается |
| — | платит только способом, уже сохранённым на сайте; карты и пароли не вводит никогда; нет способа — «оплати сама, ссылка: …»; сумма выше лимита — отказ с объяснением |

### Память

| Вы пишете | JARVIS делает |
|---|---|
| «Запомни: в ESSA не используем эмодзи в постах» | сохраняет и отвечает «🧠 запомнил: … (файл)» |
| Новый разговор после `/new` | помнит сохранённое |
| — | после задач сам записывает уроки и решения — и каждый раз сообщает, что записал |

### Навыки и помощники

| Что происходит | Что видите вы |
|---|---|
| Агент заметил повторяемый алгоритм и написал навык | «Новый навык <имя>: <описание>. Тест: пройден/нет. [Активировать] [Посмотреть] [Удалить черновик]» |
| Вы нажали «Активировать» | навык доступен со следующего сообщения |
| Не нажали | навык не работает |
| Базовые помощники | `researcher`, `competitor-analyst`, `strategist`, `copywriter`, `reels-producer`, `reviewer` — лежат черновиками, включаете вы |

## 2. Чего не умеет (и когда появится)

| Не умеет в MVP | Когда |
|---|---|
| Сам присылать «3 темы на сегодня» в 07:00 (тренд-радар по расписанию) | V0.6 |
| Работать по расписанию, воскресный отчёт и план недели, реагировать на новые файлы для ESSA | V0.7 |
| Вести неделю контента автономно | V1.0 |
| Gmail, Календарь, Google Drive, Docs, Sheets | V1.1 |
| Делать готовые видео (mp4 с титрами и музыкой) | V1.2 |
| Управлять программами на компьютере (Excel и др.) | V1.3 |
| Ходить на встречи в Zoom и делать итоги | V1.4 |
| Пульт Control Room с агентами в реальном времени | V2.0 |
| Публиковать в соцсети сам | не планируется, пока не решено иначе |
| Оплачивать картой, вводить пароли | никогда |
| Работать, когда компьютер выключен или спит | — (при включении сообщает «JARVIS снова на связи» и обрабатывает пропущенное по порядку) |

## 4. Этапы и Definition of Done

Каждый этап сдаётся только когда выполнены все проверки в колонке «Готово, когда».

| Этап | Что строим | Готово, когда (проверяемо) |
|---|---|---|
| **V0.1a** | Каркас, `.env.example`, `start.bat`, `settings.json`, Guard + `policy.yaml` | тесты Guard зелёные: чтение `.env` → отказ; запись в `.claude/settings.json` → отказ; `rm` → запрос подтверждения; чтение essa-ai/ → пропуск. Ни одного `--dangerously-skip-permissions` в коде |
| **V0.1b** | `claude_bridge` + `sessions` + `events` | на фейковом `claude`: ответ разобран, `session_id` сохранён, второй ход идёт с `--resume`, битая сессия → новая. Реальный `claude -p` на машине отвечает на «привет» по подписке |
| **V0.1c** | Telegram: allow-list, очередь, статус, `/new` `/stop`, разбиение, файлы | с телефона: «привет» → ответ; сообщение с чужого аккаунта → тишина; два сообщения подряд → второе в очереди; `/stop` останавливает |
| **V0.1d** | Approvals API + кнопки | тестовый вызов EXTERNAL → кнопки в Telegram → «Отклонить» → действие не выполнено, запись в `approvals.jsonl`; нет ответа 10 мин → отказ |
| **V0.1e** | Голос | 5 голосовых на русском распознаны и выполнены |
| **V0.2** | Папка `essa-ai/` с профилем-шаблоном | структура создана, метки `[ЗАПОЛНИ]` на месте; «что ты знаешь про ESSA?» → агент читает профиль и перечисляет, чего не хватает |
| **V0.3** | Личность, память, правила, хуки памяти | `CLAUDE.md + SOUL + GOALS + MEMORY` ≤ 12 KB (скрипт); «запомни X» → запись + «🧠 запомнил»; новая сессия знает X |
| **V0.4** | 7 контентных навыков + Playwright MCP + browser-use | с телефона «Сделай контент для ESSA на завтра» → пост, карусель, Reels, Stories в Telegram и в `content/`, источники в `sources.md` |
| **V0.5** | Поручения в браузере | «Положи в корзину Самоката …» → скриншот корзины; «Подбери билеты …» → 3 варианта; оформление → кнопка MONEY с суммой |
| **V0.6-lite** | create-skill / create-agent + activation + базовые агенты-черновики | агент создаёт черновик навыка с `TEST.md` → кнопка «Активировать» → навык доступен в следующем ходе; без нажатия — недоступен |

## 5. Что нужно от владелицы

Эти шаги делаете **вы сами** — агент не видит и не вводит ни токенов, ни паролей.

| # | Что | Где | Как |
|---|---|---|---|
| 1 | **Войти в Claude Code на компьютере** своей подпиской | Windows, где работает JARVIS | один раз войти в `claude` своим аккаунтом; `ANTHROPIC_API_KEY` в системе быть не должно |
| 2 | **Создать бота и вписать токен** `TELEGRAM_BOT_TOKEN` | файл `.env` (копия `.env.example`) | создать бота у @BotFather и вписать токен **сама**; никому его не пересылать, в том числе боту |
| 3 | **Указать свой Telegram ID** `TELEGRAM_OWNER_ID` | файл `.env` | числовой ID; бот подскажет его командой `/whoami` в режиме настройки. Пока ID не указан, бот не отвечает никому |
| 4 | **Заполнить профиль ESSA.AI** | `essa-ai/*.md` | заменить метки `[ЗАПОЛНИ: …]` в PROFILE, VOICE, AUDIENCE, PRODUCTS, STRATEGY, ANALYTICS — или прислать материалы боту |
| 5 | **Проверить личность и цели** | `SOUL.md`, `GOALS.md` | черновик с метками готовит сборка, финальный текст — за вами |
| 6 | **Войти на сайты в браузере JARVIS** | профиль браузера JARVIS | `/browser login <сайт>` — на компьютере откроется окно, войдите сами (Самокат, Авиасейлс, Instagram). Для оплаты — сохраните способ оплаты на сайте сами |
| 7 | **Задать лимит суммы покупки** | `runtime/policy.yaml` | значение `[ЗАПОЛНИ]`; менять может только владелица руками |

## 6. Как проверить готовность

Сценарий приёмки. Проходится с телефона, по порядку. Каждый шаг — ожидаемый результат.

### Шаг 0. Запуск

| Действие | Ожидаемо |
|---|---|
| Запустить `start.bat` на компьютере | в Telegram приходит «JARVIS снова на связи» |
| Перезагрузить компьютер | после входа в Windows JARVIS стартует сам (Планировщик задач) |

### Шаг 1. Связь и доступ

| Вы делаете | Ожидаемо |
|---|---|
| Пишете «привет» | ответ в том же чате |
| Пишете боту с другого аккаунта | тишина |
| Пишете две задачи подряд | вторая: «принял, возьму после текущей задачи (в очереди: 1)» |
| Во время задачи — `/stop` | статус «остановлено» |
| `/new` | следующий ответ — в новом разговоре |
| Наговариваете «Привет, что ты умеешь?» | «🎙 распознал: …» и ответ |
| Присылаете фото и пишете «что на фото?» | агент описывает фото |

### Шаг 2. Профиль ESSA.AI

| Вы пишете | Ожидаемо |
|---|---|
| «Что ты знаешь про ESSA?» | агент читает профиль в `essa-ai/` и перечисляет, чего не хватает (метки `[ЗАПОЛНИ]`) |

### Шаг 3. Память

| Вы пишете | Ожидаемо |
|---|---|
| «Запомни: в ESSA не используем эмодзи в постах» | «🧠 запомнил: … (файл)» |
| `/new`, затем «Что ты знаешь про эмодзи в постах ESSA?» | помнит |

### Шаг 4. Контент

| Вы пишете | Ожидаемо |
|---|---|
| «Сделай контент для ESSA на завтра» | статус обновляется; приходят пост, карусель, Reels-сценарий, Stories с пометкой «черновик — ждёт твоего решения» |
| Проверить папку | `essa-ai/content/<дата>-<тема>/` с `post.md`, `carousel.md`, `reels.md`, `stories.md`, `sources.md` |
| Нажать «Опубликовано» | строка в `PUBLISHED.md` |

### Шаг 5. Браузер и деньги

| Вы пишете | Ожидаемо |
|---|---|
| `/browser login samokat` (вход сами) | окно браузера на компьютере |
| «Положи в корзину Самоката молоко и хлеб» | скриншот корзины и сумма |
| «Оформи заказ» | кнопка «Подтвердить» с суммой и составом → нажать «Отклонить» → заказ не оформлен, запись в `approvals.jsonl` |
| «Подбери билеты в Москву на пятницу» | три варианта со скриншотами, выбор кнопкой |
| Не отвечать на кнопку подтверждения 10 минут | отказ |

### Шаг 6. Безопасность (проверяет разработчик)

| Проверка | Ожидаемо |
|---|---|
| Попросить агента прочитать `.env` | отказ |
| Попросить изменить `.claude/settings.json` | отказ |
| Попросить удалить файл | кнопка «Подтвердить» (IRREVERSIBLE) |
| Поиск `--dangerously-skip-permissions` по коду | ничего не найдено |
| Скрипт размеров `CLAUDE.md + SOUL + GOALS + MEMORY` | ≤ 12 KB |

### Шаг 7. Навыки

| Действие | Ожидаемо |
|---|---|
| Дать повторяющуюся задачу, после которой агент предлагает навык | «Новый навык <имя>: … Тест: пройден/нет. [Активировать] [Посмотреть] [Удалить черновик]» |
| Не нажимать | навык недоступен |
| Нажать «Активировать» | навык работает в следующем сообщении |

**MVP готов**, когда все шаги 0–7 пройдены.
