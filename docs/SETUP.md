# SETUP — как запустить JARVIS

Пошагово, по порядку. Программировать не нужно: везде достаточно скопировать команду,
нажать Enter и вписать пару значений в один файл. Все шаги делаются один раз.

> **Про секреты.** В этом документе нет ни одного настоящего значения — только имена строк,
> которые вы впишете сами в файл `.env`. Никому не показывайте его содержимое: агент
> читать `.env` не может, и это правильно.

---

## Шаг 0. Что нужно на компьютере (один раз)

1. **Windows 10 или 11** — на нём всё и работает.
2. **Python 3.12** — с python.org, при установке галочка «Add Python to PATH».
3. **Git for Windows** — без него не работают защитные хуки Claude Code.
4. **Node.js** — нужен браузерным задачам (`npx`).
5. **Claude Code** — тот самый `claude`, которым JARVIS думает.

Затем один раз создайте окружение. Откройте «Терминал» в папке проекта и выполните:

```
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

После установки зависимостей — браузер для снимков карусели: `python -m playwright install chromium` (питоном из `.venv`).

## Шаг 1. Вход в Claude

В терминале:

```
claude
```

Внутри наберите:

```
/login
```

Откроется браузер, войдите в свой аккаунт Claude. Это самое важное: JARVIS думает вашей
подпиской. Закройте `claude` (Ctrl+C или `/exit`).

Проверить, что вход живой, можно в любой момент — просто запустите `claude` и напишите ему
что угодно. Если он отвечает — всё в порядке.

## Шаг 2. Свой бот в Telegram

1. В Telegram найдите **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и адрес бота (адрес заканчивается на `bot`).
3. BotFather пришлёт **токен** — длинную строку. Это пароль от бота, никому его не давайте.

Теперь откройте в папке проекта файл **`.env`** (если его нет, скопируйте `.env.example`
и назовите копию `.env`). В нём четыре строки; значения вписываете вы сами:

```
TELEGRAM_BOT_TOKEN=
TELEGRAM_OWNER_ID=
JARVIS_DAILY_RUN_BUDGET=
JARVIS_PURCHASE_LIMIT_RUB=
```

Что писать сразу после знака «=», без пробелов и кавычек:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather.
- `TELEGRAM_OWNER_ID` — пока оставьте пустым, заполним на шаге 4.
- `JARVIS_DAILY_RUN_BUDGET` — сколько задач в сутки; можно не трогать, по умолчанию 100.
- `JARVIS_PURCHASE_LIMIT_RUB` — потолок покупки в рублях; выше него — отказ без вопроса.

Сохраните файл.

## Шаг 3. Первый запуск

Дважды щёлкните **`start.bat`** в папке проекта. Откроется чёрное окно — это нормально,
пока оно открыто, бот на связи. Закрывать его не нужно; чтобы выключить бота — закройте.

В Telegram напишите своему боту `/start`.

## Шаг 4. Сказать боту, кто хозяйка

Отправьте боту:

```
/whoami
```

Он ответит числом — это ваш Telegram ID. Впишите это число в `.env` в строку
`TELEGRAM_OWNER_ID=`, сохраните файл и перезапустите `start.bat` (закрыть окно и открыть снова).

После перезапуска бот здоровается сам: «JARVIS на связи». С этого момента он отвечает
только вам: сообщения с любых других аккаунтов он молча игнорирует.

## Шаг 5. Автозапуск после перезагрузки

Чтобы JARVIS поднимался сам при входе в Windows, один раз выполните в терминале, находясь
в папке проекта:

```
powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1
```

Выключить автозапуск:

```
powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1 -Remove
```

## Шаг 6. Вход на сайты

JARVIS работает в отдельном браузерном профиле, и пароли вводите только вы. Когда нужен сайт
с личным кабинетом, напишите боту:

```
/browser_login https://адрес-сайта
```

Откроется окно браузера — войдите в нём как обычно (пароль, код из SMS). Закройте окно.
Вход запомнится, и дальше JARVIS сможет работать на этом сайте сам. Пароли он не видит
и вводить их не умеет — это запрещено на уровне защиты.

## Шаг 7. Рассказать о себе и о деле

Чем лучше заполнены эти файлы, тем точнее ответы. Открывайте обычным блокнотом и пишите
своими словами, метки `[ЗАПОЛНИ]` заменяйте текстом.

| Файл | О чём |
|---|---|
| `GOALS.md` | ваши цели на ближайшее время — по ним агент расставляет приоритеты |
| `SOUL.md` | какой характер у JARVIS, как с вами разговаривать |
| `essa-ai/PROFILE.md` | что такое ESSA.AI, чем занимаетесь |
| `essa-ai/VOICE.md` | как звучат ваши тексты: слова, длина, что нельзя |
| `essa-ai/AUDIENCE.md` | для кого вы пишете |
| `essa-ai/PRODUCTS.md` | что продаёте |
| `essa-ai/STRATEGY.md`, `essa-ai/ANALYTICS.md` | цели по контенту и что уже работало |

Можно и не открывать файлы: напишите боту «запомни: …», и он запишет сам — в ответе появится
строка «🧠 запомнил: …».

Проверить, чего ему не хватает, просто: напишите «Что ты знаешь про ESSA?» — он прочитает
профиль и перечислит пустые места.

## Шаг 8. Проверка, что всё готово

Полный список — в `docs/MVP.md`, раздел «Как проверить готовность». Коротко, с телефона:

1. `start.bat` запущен → в Telegram «JARVIS на связи».
2. «привет» → ответ; сообщение с чужого аккаунта → тишина.
3. Две задачи подряд → вторая: «принял, возьму после текущей задачи».
4. `/stop` во время задачи → «остановлено»; `/new` → разговор с чистого листа.
5. Голосовое → «🎙 распознал: …» и ответ. Фото → агент его видит.
6. «Что ты знаешь про ESSA?» → перечисляет, чего не хватает в профиле.
7. «Запомни: …», потом `/new` и вопрос про это же → помнит.
8. «Сделай контент для ESSA на завтра» → пост, карусель, Reels, Stories и кнопки
   «Принято / Переделать / Опубликовано».
9. Любое действие наружу (отправить, оформить, оплатить) → кнопки «Подтвердить / Отклонить».
   Нажмите «Отклонить» — действие не выполнится.

Прошли все пункты — система готова.

> **Важно: при сборке эта проверка не выполнялась.** Сквозной прогон с настоящим `claude`,
> голосовыми и Telegram сделать не удалось — на компьютере истёк вход в Claude
> (`auth_required`). Офлайн вся цепочка подтверждена тестами (прогон `pytest` зелёный, включая
> сквозной `tests/test_e2e_offline.py`), защитные хуки проверены вживую
> (`scripts\check_hooks.py`). Живой прогон делаете вы после шага 1 (`claude` + `/login`):
> сначала `.venv\Scripts\python.exe tests\smoke_real_turn.py` — он должен ответить по профилю
> ESSA и получить отказ Guard на попытку прочитать `.env`, — и затем пункты 1–9 выше.

## Если что-то пошло не так

**«Нужно заново войти в Claude на компьютере».**
Истёк вход в Claude — подписка отвязалась, сам он не восстановится. Откройте терминал,
выполните `claude`, затем `/login`, войдите в браузере. Бота перезапускать не нужно:
следующее сообщение уже пройдёт.

**«Не вижу TELEGRAM_BOT_TOKEN».**
Файл `.env` лежит не рядом со `start.bat`, назван иначе (например, `.env.txt`) или строка
пустая. Проверьте: файл называется ровно `.env`, в нём есть строка `TELEGRAM_BOT_TOKEN=` и
сразу за знаком «=» — токен от BotFather, без кавычек и пробелов. Сохраните и перезапустите
`start.bat`.

**Бот молчит на все сообщения.**
Скорее всего, пуст `TELEGRAM_OWNER_ID`: бот в режиме настройки и отвечает только на `/whoami`.
Вернитесь к шагу 4.

**«.venv not found» в чёрном окне.**
Не создано окружение Python — выполните две команды из шага 0.

**Браузер не открывается / «профиль занят».**
Браузерным профилем может пользоваться только один процесс. Дождитесь окончания задачи
(или `/stop`), закройте все окна браузера JARVIS и повторите `/browser_login`.

**Сайт просит капчу, код из SMS или вход.**
Так и задумано: JARVIS останавливается и пишет, что нужны вы. Сделайте этот шаг сами через
`/browser_login` и повторите задачу.

**«Лимит подписки Claude исчерпан».**
Кончились лимиты Claude на период. JARVIS сам скажет, когда они обновятся; задачу можно
повторить после этого времени.

**Кнопка отвечает «запрос уже неактуален».**
На подтверждение есть 10 минут. Если не успели — действие отменено, просто попросите заново.
