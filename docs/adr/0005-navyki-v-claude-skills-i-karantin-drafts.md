# ADR 0005 — Навыки и агенты в `.claude/`, самосозданные — через карантин `drafts/` и кнопку владелицы

- Статус: принято (2026-09-18)
- Контекст: в исходном дереве брифа навыки лежали в `skills/` в корне (R09). Claude Code нативно подгружает навыки только из `.claude/skills/` — только оттуда работают прогрессивная загрузка (описание в контексте, тело по необходимости) и живая перезагрузка. Класть их в другое место значит писать обвязку, которая копирует то, что уже есть. Одновременно агент по R33/G04 сам пишет себе навыки, а по R34/G01 — субагентов; если он пишет их сразу в рабочую папку, он расширяет собственные возможности без ведома владелицы.
- Решение: активные навыки — в `.claude/skills/`, активные субагенты — в `.claude/agents/`; отступление от дерева брифа зафиксировано. Запись в эти папки агенту запрещена. Всё, что агент создаёт сам, идёт в `drafts/skills/<имя>/` или `drafts/agents/<имя>.md`. Навык-черновик обязан нести `SKILL.md` и `TEST.md` со сценарием и результатом прогона (методика Superpowers: сперва проваленный тест без навыка, потом навык). Мост замечает черновик и показывает в Telegram «Новый навык <имя>: <описание>. Тест: пройден/нет. [Активировать] [Посмотреть] [Удалить черновик]»; перенос делает `activation.activate`, то есть Python, а не агент. Папка `.claude/agents/` создаётся мостом заранее — первый файл в новой папке потребовал бы перезапуска. Для разовой задачи агент берёт встроенного универсального субагента и файл не заводит.
- Альтернативы: (а) `skills/` из брифа + свой загрузчик — отвергнуто: обвязка ради совместимости с черновиком дерева; (б) автоактивация после зелёного теста — отвергнуто: тест пишет тот же агент, что и навык, это самоподпись; (в) держать десяток постоянных субагентов — отвергнуто (R28, «не пять агентов»): определения лежат, запускаются под задачу и завершаются.
- Последствия: любой новый навык ждёт человека — ночью агент не научится ничему, что применит утром. Владелица оказывается ревьюером кода и промптов, хотя она не разработчик: описание и `TEST.md` обязаны быть читаемы ей, иначе кнопка «Активировать» нажимается вслепую и защита превращается в ритуал. `drafts/` со временем зарастает отклонёнными черновиками и требует уборки. Путь `.claude/skills/` фиксирует привязку к соглашениям Claude Code (см. ADR 0001).
