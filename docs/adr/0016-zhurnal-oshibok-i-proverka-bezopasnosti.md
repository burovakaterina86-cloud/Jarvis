# ADR 0016 — Журнал ошибок, окружение без секретов и усиление Guard (ревью 2026-10-07)

- Статус: принято (2026-10-07).
- Контекст: ошибки бота записывались только именем типа (`RuntimeError`), без причины и трассировки; нигде не было механизма, который возвращал бы агенту его повторяющиеся ошибки. Ревью кода и проверка Guard нашли реальные дыры: токен бота в адресе не маскировался, дочерние процессы наследовали все ключи из `.env`, Guard пропускал `runtime./policy.yaml` (точка в конце имени), файлы запуска в корне проекта (`argparse.py` подменял стандартный модуль внутри `python -m integrations.*`), выгрузку данных через `curl -T`/`ssh`/`nc`, запуск `.ps1`/`.sh`/`bash -c`, `file://` в WebFetch.
- Решение:
  1. **Журнал ошибок** `runtime/errorlog.py`: `state/errors.jsonl` (событие: причина, трассировка без секретов) и `state/errors_index.json` (счётчик повторов по отпечатку). Подвешен на `logging` (все WARNING и выше), на мост, очередь, расписание, фоновые работы; ошибки инструментов агента и отказы Guard пишутся как `kind=agent`. Памятка «это уже не получалось» (`errorlog.digest`) вставляется в начало сессии хуком `session_start`. Подсказку «делай так» ставит человек: `python -m runtime.errorlog hint <fp> <текст>`.
  2. **Секреты**: `runtime/secretenv.py` — `scrub()` убирает из окружения дочерних процессов всё, что похоже на секрет; ключи модули берут из `.env` сами и только свои (`lookup`, `load_dotenv(only=…)`). Исключение — `GROQ_API_KEY` для вендорных скриптов транскрибации.
  3. **Остановка процессов** `runtime/procutil.py`: `taskkill /T` в отдельном потоке (бот не замирает), отмена хода убивает процесс, `/stop` в паузе между запусками не теряется.
  4. **Guard**: имена путей как их видит Windows (точки/пробелы/потоки), реальный путь после junction и коротких имён, `protected_root_files`, `tests/**`, `conftest.py`; схема адреса только http/https; адреса в командах; выгрузка данных, прямые сетевые утилиты, другие интерпретаторы и запуск файлов-скриптов — кнопка; номер карты и «Buy/Place order» в браузере — отказ.
  5. **Браузерный рендер монтажа** пускает страницу только к своим папкам (`render.mjs`: перехват запросов).
  6. **Stop-хук** `capture_learning` переведён на документированный `{"decision": "block", "reason": …}`.
- Альтернативы: (а) писать ошибки в `memory/` — отвергнуто: машинные записи с трассировками засоряют память владелицы; (б) белый список окружения вместо `scrub` — отвергнуто: у `claude` и `node` десятки нужных системных переменных; (в) CSP на странице оверлея монтажа — отложено: без запуска браузера не проверить, что маски и шрифты не сломаются; перехват запросов закрывает ту же угрозу.
- Последствия: ключи сервисов должны лежать в `.env` (а не только в окружении процесса бота); обычные команды вроде `curl -sSL` и `git commit -m "$(cat <<EOF…)"` проходят, а `bash`, `ssh`, `curl -T` теперь спрашивают кнопку.
