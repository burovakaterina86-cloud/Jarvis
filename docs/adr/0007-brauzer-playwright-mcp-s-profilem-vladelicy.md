# ADR 0007 — Браузер: Playwright MCP на общем профиле, вход делает владелица сама

- Статус: принято (2026-09-18)
- Контекст: половина сценариев (тренды, конкуренты, корзина Самоката, билеты, комментарии в Instagram) требует живого браузера с логинами. Логины нельзя дать агенту как секрет: он не должен видеть и вводить пароли. Библиотека browser-use тянет собственный LLM-ключ — то есть второй мозг и вторые деньги, ровно то, что отвергнуто в ADR 0001.
- Решение: `@playwright/mcp` с `--user-data-dir state/browser-profile` на Edge/Chrome. Профиль постоянный и один: владелица один раз входит на сайт сама через `/browser login <сайт>`, окно открывается у неё на компьютере. Агент работает в уже авторизованном профиле, пароли не видит; прямое чтение `state/browser-profile/` запрещено deny-правилами и Guard, ввод в поля password и карты Guard отклоняет. Капча, вход, SMS-подтверждение — остановка с сообщением «нужен ты: <что>», обход не пытаемся. Содержимое страниц — недоверенные данные по `.claude/rules/untrusted-content.md`: любое действие, «предложенное» страницей, проходит как EXTERNAL. Один профиль означает один браузер одновременно, поэтому браузерные задачи стоят в глобальной последовательной очереди.
- Альтернативы: (а) browser-use — отвергнута: свой LLM-ключ, свой цикл принятия решений, дублирует Claude; (б) отдельный headless-профиль с автологином из хранилища паролей — отвергнуто: потребовало бы дать агенту доступ к паролям, чего защита как раз не допускает; (в) официальные API площадок — отвергнуто для первой версии: для Instagram и магазинов это отдельные приложения, ключи и модерация.
- Последствия: сессии в профиле истекают, и агент периодически будет останавливаться на «войди сама» — это нормальный режим, а не сбой. Браузерные задачи не распараллеливаются: длинное исследование блокирует корзину. Смена вида страницы или капча ломают сценарий, и починка — это правка навыка `browser-use`, а не ретрай. Профиль — самый чувствительный каталог проекта: он в `.gitignore`, лежит в `state/` и по сути равен доступу ко всем аккаунтам владелицы.
