# ADR 0002 — Подтверждения — собственный Guard-хук и локальный Approvals API, fail-closed

- Статус: принято (2026-09-18)
- Контекст: агент действует в браузере под живыми логинами владелицы и имеет доступ к её файлам. Нужен барьер, который нельзя обойти уговорами в промпте и который не открывается сам при сбое. Штатные пути не подошли: схема `--permission-prompt-tool` не документирована, а официальный Telegram-плагин channels — research preview, требует Bun и держит сессию открытой. В референсе claude-telegram-agent хуки висели только на Bash/Read/Edit/Write (Grep, Glob и MCP проходили мимо) и работали fail-open — при ошибке хука действие выполнялось.
- Решение: свой хук `PreToolUse` с matcher `*`, включая `mcp__*`, вызываемый абсолютным путём к `python.exe` из venv. Он классифицирует вызов по таблице `runtime/policy.yaml` на четыре уровня: READ — сразу; WRITE внутри корня JARVIS — сразу; EXTERNAL (отправить, опубликовать, ответить человеку, зарегистрировать) — кнопка «Подтвердить»; IRREVERSIBLE/MONEY (оплата, бронь, покупка, удаление) — кнопка всегда, с явной суммой и объектом, отключить нельзя. Для EXTERNAL/MONEY хук блокирующе стучится в Approvals API моста на `127.0.0.1` с одноразовым токеном из `state/secrets/`, тот показывает кнопки в Telegram. Fail-closed: нет ответа за 10 минут — отказ; ошибка самого хука — отказ (exit 2); неизвестный MCP-инструмент — EXTERNAL по умолчанию. Запуск всегда с `--permission-mode dontAsk` и явными разрешениями; `--dangerously-skip-permissions` в проекте нет нигде, это проверяется тестом строки запуска.
- Альтернативы: `--permission-prompt-tool` — отвергнут (недокументированный контракт, завязка на непубличную схему); плагин channels — отвергнут (preview, чужая рантайм-зависимость, постоянно открытая сессия); подтверждения на уровне промпта/правил — отвергнуты: текст в контексте не барьер, его снимает удачная формулировка или недоверенный текст со страницы; fail-open ради удобства — отвергнут: именно сбой хука и есть момент, когда защита нужнее всего.
- Последствия: любой сбой Guard, Approvals API или Telegram останавливает работу агента — это выбрано осознанно, «тихого продолжения» не бывает. Задержка на каждом внешнем действии и необходимость быть у телефона; десятиминутный таймаут превращает долгие цепочки в прерываемые. Каждый новый инструмент и MCP-сервер требует строки в `policy.yaml`, иначе он молча деградирует до EXTERNAL и спрашивает по любому поводу. Заводить карту карты/CVV агент не может в принципе — платить можно только способом, уже сохранённым на сайте владелицей.
