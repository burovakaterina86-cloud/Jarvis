# План: собеседник на Haiku

Спецификация: docs/superpowers/specs/2026-10-07-dialogue-agent.md.

## Общие ограничения

Сохранить незакоммиченные материалы и state; не читать секреты; не устанавливать пакеты; не перезапускать живой бот в ходе разработки. Каждое исправление — отдельный коммит и push в Jarvis.git. Rollback: откатить коммиты к d09cb0b; новые данные state оставить, старые сессии не изменять.

## 1. Изолированный собеседник

Файлы: runtime/conversation.py, runtime/prompts/conversation.md, runtime/conversation-settings.json, runtime/claude_bridge.py, runtime/task_router.py, tests/test_conversation.py.

Красные тесты: строгая схема, отсутствие инструментов, Haiku, независимая очередь и бюджет, история без потери исходника. Реализовать отдельный тип Job/context, ограниченную историю и вызов CLI. Проверить `.venv\Scripts\python.exe -m pytest -q tests/test_conversation.py tests/test_bridge.py` (уточнить имя модуля по дереву). Ожидание: все тесты зелёные, разговор без запуска инструментов.

## 2. Вход сообщений и отдельные задачи

Файлы: integrations/telegram/gateway.py, runtime/task_router.py, runtime/review.py, tests/test_conversation.py, тестовые фикстуры Telegram.

Красные тесты: вопрос при заблокированном исполнителе, новая задача без чужой сессии, строгая роль, сохранённая карточка, ошибка модели не попадает в рабочую очередь, stop не присылает поздний ответ. Подключить собеседника к каждому сообщению; явное продолжение после кнопки переключения минует повторную классификацию. Сохранить проверки текстового конвейера и ревью. Команды, подтверждения и статусы остаются прямыми обработчиками.

## 3. Проверка и сдача

Команды: полный pytest; scripts/check_context_size.py; scripts/sync_mirrors.py --check. Прогон хуков — только с изоляцией боевых журналов. Один свежий независимый reviewer всей ветки, исправить замечания. Безопасный живой запрос Haiku без инструментов, измерить время, не обещать гарантированный срок. Документировать границы специализации и состояние живого бота. Коммит и push точных файлов, проверить удалённый SHA.

## Фокус ревью

Потеря исходного запроса; исполнение по испорченной схеме; смешение сессий и аккаунтов; поздняя отправка после stop; разговор расходует весь рабочий бюджет; пропущенный контроль результата; изменение чужих файлов; незаявленный перезапуск бота.
