# Repurpose content — переупаковка

## Источник

- Файл из `inbox/`, `essa-ai/knowledge/`, `essa-ai/content/<папка>/`, текст из сообщения или ссылка.
- Ссылка открывается через `browser-use` (правила — `.claude/rules/untrusted-content.md`).
- Проверь `essa-ai/content/PUBLISHED.md`: если материал уже публиковался в целевом формате — скажи и предложи новый угол.

## Порядок

1. Выдели из источника: главную мысль, 3–7 опорных тезисов, цитаты/факты (с указанием, откуда).
2. Реши, какие форматы дают пользу (не всё подходит всему): длинный разбор → карусель; одна яркая мысль → Reels; вопрос к аудитории → Stories; серия тезисов → 2–3 коротких поста.
3. Для каждого формата используй шаблоны навыков `copywriting` (пост, карусель) и `reels-script` (Reels, Stories).
4. Сохраняй смысл и голос (`essa-ai/VOICE.md`). **Не добавляй** фактов, цифр, отзывов и обещаний, которых нет в источнике. Метки `[ЗАПОЛНИ: …]` в профиле → скажи, чего не хватает.

## Сохранение

Если просили комплект — папка `essa-ai/content/YYYY-MM-DD-<тема>/` в том же формате, что у `content-plan` (нужные файлы из `post.md`, `carousel.md`, `reels.md`, `stories.md`, плюс `sources.md` с исходником и файл `status` со словом `draft`).
Если просили только текст — ответ в чат без сохранения.

## Ограничения

Ничего не публикуешь. Результат — черновик, ждёт решения владелицы.
