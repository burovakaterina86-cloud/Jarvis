# Competitor research — разбор конкурентов

Ничего не публикуешь, не подписываешься, не лайкаешь и не пишешь конкурентам.

## Кого смотреть

1. Список конкурентов — в `essa-ai/STRATEGY.md` или `essa-ai/knowledge/` (если он там есть).
2. Если списка нет или стоит `[ЗАПОЛНИ: …]` — скажи об этом владелице и предложи 3–5 кандидатов, найденных поиском, **с пометкой «кандидат, подтверди»**. Не называй их конкурентами как факт.
3. Позиционирование ESSA бери из `essa-ai/PROFILE.md` и `essa-ai/PRODUCTS.md`; не заполнено — не придумывай, сравнивай только по контенту.

## Что собрать по каждому (последние 2–4 недели)

- Площадка и ссылка на профиль.
- 3–5 публикаций с наибольшим откликом, который **виден на странице** (ссылка + дата).
- Форматы: пост / карусель / Reels / Stories; частота.
- Повторяющиеся темы и крючки (первая строка, обложка, первые 3 секунды Reels).
- Что не покрыто — возможность для ESSA.

Браузер — по навыку `browser-use`: `browser_snapshot` для чтения, скриншот только для отчёта.

## Правила достоверности

- Каждое утверждение о конкуренте — со ссылкой и датой просмотра.
- Цифры (подписчики, просмотры) — только если видны на странице, с датой.
- Вывод без подтверждения — «гипотеза».
- Не копировать тексты конкурентов: пересказ идеи в одну фразу, не цитаты целиком.

## Формат результата

```
## Конкуренты — <YYYY-MM-DD>
### <Имя/аккаунт> — <URL>
- Сильные темы: … (пример: <URL>, <дата>)
- Форматы и частота: …
- Крючки: …
### Свободные места для ESSA
1. <Идея> — почему: … (основание: <URL> / гипотеза)
```

Если вызвано из `content-plan`, ссылки попадают в `sources.md` комплекта.
