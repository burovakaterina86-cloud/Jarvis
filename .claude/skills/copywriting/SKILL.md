# Copywriting — пост и карусель

## Конвейер (обязателен)

Текст в один проход больше не пишется. Порядок — её контракт:

`content brief → textwriter → humaniser → VOICE/preflight → final`

1. Бриф материала — из `content-strategy` (или собери коротко сама).
2. Первый проход — навык `textwriter`: языковое исполнение брифа.
3. Второй проход, обязательный, — навык `humaniser`: очистка от нейросетевых клише.
   Он не имеет права менять FUNNEL_STAGE, FUNCTION, BELIEF_BEFORE → BELIEF_AFTER,
   MAIN_IDEA и CTA.
4. Сверка с `essa-ai/VOICE.md` и самопроверка ниже — и только потом финал владелице.

Отметка о проходе остаётся в папке комплекта последней строкой файла с текстом:

```
<!-- pipeline: textwriter → humaniser → VOICE — пройден ГГГГ-ММ-ДД -->
```

Проход почему-то не выполнен — текст всё равно доходит до владелицы, но с честной
пометкой вместо этой строки и строкой об этом в ответе:

```
<!-- pipeline: humaniser НЕ пройден — <причина> -->
```

## Перед письмом

1. `essa-ai/VOICE.md` — тон, слова, запреты. Метка `[ЗАПОЛНИ: …]` → скажи «голос бренда не заполнен, пишу нейтрально-дружелюбно — поправь VOICE.md» и не имитируй «фирменный стиль».
2. Блок «Решение по теме» из `content-strategy` (или собери его сама коротко).
3. `essa-ai/PRODUCTS.md` — упоминать только то, что там есть. Цен, скидок, сроков, гарантий, кейсов, отзывов и цифр, которых нет в файлах или источниках, не писать; нужен пример — `[пример от владелицы]`.

> Маршрут «какой файл читать» — `essa-ai/INDEX.md`. Читай два-три названных им файла, не папку. Файлы больше ~30 КБ (склейки, `MASTER PROMPT`, `DESIGN.md`) — только `Grep`, целиком никогда.

## Пост (`post.md`)

```
# <Заголовок / первая строка-крючок>

<Текст: крючок → проблема/наблюдение → суть (2–4 абзаца или список) → вывод>

<Призыв к действию>

<Хештеги: 3–7, по теме>
```

- Первая строка сама по себе цепляет (вопрос, неожиданный тезис, боль).
- Абзацы короткие, 1–3 предложения. Без канцелярита и штампов «в современном мире».
- Длина — до ~2200 символов (лимит подписи Instagram), обычно 800–1500.
- Факт из тренда — со ссылкой в `sources.md`, в тексте без ссылки.

## Карусель (`carousel.md`)

```
# Карусель: <тема>

## Слайд 1 — обложка
Текст: <крючок, до 8–10 слов>
Визуал: <что на слайде>

## Слайд 2
Текст: …
Визуал: …

…

## Слайд N — финал
Текст: <вывод + призыв: сохранить / написать / перейти>

## Подпись к карусели
<2–5 предложений + хештеги>
```

- 6–10 слайдов, одна мысль на слайд, до ~30 слов на слайде.
- Обложка обещает конкретную пользу.
- Последний слайд — действие.

## Самопроверка перед отдачей

- [ ] Нет выдуманных фактов, цифр, отзывов, продуктов.
- [ ] Тон соответствует VOICE.md (или сказано, что он не заполнен).
- [ ] Тема не повторяет `essa-ai/content/PUBLISHED.md` без нового угла.
- [ ] Текст — черновик: ничего не публикуешь и не отправляешь.
- [ ] Оба прохода выполнены, отметка `<!-- pipeline: … -->` стоит в файле (или стоит честная пометка, что очистку текст не прошёл).
