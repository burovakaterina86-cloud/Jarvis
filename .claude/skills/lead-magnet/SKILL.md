# Lead Magnet — материал для воронки ESSA.AI

## Происхождение метода

Шаги (проверка темы по матрице зрелости — на ступень выше аудитории и с прицелом
в её ложное убеждение, согласование плана до текста, чек-лист перед сдачей)
взяты из `anthropic-skills:skill-pisatel-lead-magnet-light` — это метод, не
исполняемый код. Формат выдачи здесь другой: там текстовый файл, здесь —
интерактивный HTML-гайд в её дизайн-системе через `integrations.visuals.guide`
(по умолчанию) или PDF через `integrations.visuals.leadmagnet` (по её просьбе),
и данные идут не прямо в текст, а в промежуточный `lead-magnet.json` по общему
контракту двух частей (вёрстка + текст).

## Формат выдачи

Она посмотрела PDF в системе каруселей и спросила: «а откуда ты взял этот
стиль? разве это мой стиль?» — и была права: для гайдов у неё свой стиль,
не карусельный (`ESSA_PRESENTATION_STYLE.md`). На вопрос о формате ответила
кнопкой: «Интерактивный HTML-гайд, как мои» (2026-09-23).

- **По умолчанию** — интерактивный HTML-гайд: `integrations.visuals.guide`.
  Стиль — её гайдовая палитра и приёмы из
  `essa-ai/visual_references/интерактивные гайды/*.html` и
  `.autopilot/2026-09-23-lead-magnets--wip/contract.md` (раздел «поправка
  владелицы»), а не `ESSA_PRESENTATION_STYLE.md` (это система каруселей) —
  ориентир по месту в общем дизайн-контракте: `essa-ai/DESIGN.md` §19.
- **PDF — только если она прямо попросила** «в PDF», «распечатать» и т.п.:
  `integrations.visuals.leadmagnet`.

## Шаги

1. **Сверка с воронкой.** Открой `essa-ai/05_FUNNEL.md` (шаг «маленький
   бесплатный результат → AI-аудит») и `essa-ai/04_PRODUCTS_AND_AI_WORKSHOP.md`
   §3–4 (готовый продукт «AI-аудит контент-рутины» — обычно это и есть тема
   первого лид-магнита). Новую тему предлагай только если владелица прямо
   попросила другую или главная тема уже сделана.
2. **Тема на ступень выше.** Аудитория уже умеет что-то один; лид-магнит даёт
   следующий шаг, не весь путь сразу, и целится в конкретное ложное убеждение
   аудитории (`essa-ai/02_AUDIENCE.md`, `03_BRAND_MEANINGS.md` — если там нет
   готового убеждения, спроси владелицу, не выдумывай).
3. **План — ей на согласование, до текста.** Заголовок, 3–6 разделов с
   одной мыслью на раздел, где нужна таблица для заполнения, чем закончить
   (CTA). Короткое сообщение, не файл — она подтверждает или правит.
4. **Текст.** Пишет `textwriter` по согласованному плану, обязательно проходит
   `humaniser`. Факты, цифры, примеры — только из её файлов
   (`essa-ai/EXPERTISE.md`, `04_PRODUCTS_AND_AI_WORKSHOP.md` и т.п.); нет
   данных — оставь метку `[ЗАПОЛНИ: …]` и спроси, не выдумывай. Финал — ровно
   одно мягкое приглашение к следующему шагу воронки (обычно «АУДИТ», по
   `05_FUNNEL.md`) — не два призыва и не жёсткая продажа. Заголовки CTA и
   разделов не используют чужие бренды, клубы, названия сервисов и ссылки.
5. **Данные.** Результат текста — `lead-magnet.json` в
   `essa-ai/content/lead-magnets/<slug>/` по формату из
   `.autopilot/2026-09-23-lead-magnets--wip/contract.md`:
   `title`, `subtitle`, `author`, `intro[]`, `sections[]`
   (`heading`, `body[]`, необязательные `table{columns,rows}`, `checklist[]`,
   `note`, `handwritten`), `cta{text,keyword}`, `background` (`"dark"` по
   умолчанию — печатный вариант проси явно, `"light"`). Пустые клетки
   `table.rows` — места для заполнения читателем, не прочерки и не пропуски.
6. **HTML — одной командой (по умолчанию):**

   ```
   .venv\Scripts\python.exe -m integrations.visuals.guide essa-ai\content\lead-magnets\<slug>
   ```

   Читает `<папка>\lead-magnet.json`, пишет `<папка>\<slug>.html` — один
   самодостаточный файл (CSS, JS, шрифт и её портрет внутри), открывается
   где угодно. Коды выхода: `0` — готово; `2` — ошибка данных (нет файла,
   битый JSON, неизвестное или пустое обязательное поле) — почини
   `lead-magnet.json` и прогони снова; `3` — данные верны, но файл не
   записан (ошибка диска).

   Если раздел даёт таблицу с колонками часов, частоты и раздражения —
   вёрстка сама делает её интерактивной (ввод, подсчёт итога, подсветка
   самой тяжёлой строки, сохранение в localStorage читателя).

   **PDF — по отдельной просьбе:**

   ```
   .venv\Scripts\python.exe -m integrations.visuals.leadmagnet essa-ai\content\lead-magnets\<slug>
   ```

   Тот же `lead-magnet.json`, пишет `<папка>\<slug>.pdf`. Коды выхода: `0` —
   готово; `2` — ошибка данных; `3` — вёрстка собрана, но PDF не снят
   (Playwright недоступен) — HTML остаётся на диске.
7. **Чек и сдача.** Перед тем как отдать файл: заголовок и подзаголовок на
   месте, CTA — ровно одно приглашение с её кодовым словом, ни один факт не
   выдуман, чужих брендов и ссылок нет; для HTML — посмотреть на широком и
   мобильном экране, что таблица (если есть) заполняется и считает. Сдай
   владелице путь к файлу и одну строку, что внутри.

## Безопасность

Файл лид-магнита остаётся внутри папки JARVIS (WRITE — сразу). Отправка
владелице готового файла в Telegram и публикация — не EXTERNAL для этого
навыка (файл идёт ей самой, не наружу), но любая рассылка материала кому-то
ещё — через её подтверждение, по `.claude/rules/approvals.md`.

## Связка

`textwriter` → `humaniser` пишут текст; `integrations.visuals.guide` —
вёрстка HTML-гайда (по умолчанию), `integrations.visuals.leadmagnet` —
вёрстка и PDF (по просьбе). Оба — отдельные модули от карусельного
`integrations.visuals.build`, код каруселей не трогают. Палитра и шрифт
гайда — константы в `integrations/visuals/guide.py`, снятые с её файлов
`essa-ai/visual_references/интерактивные гайды/*.html` (не
`tokens.py`/`ESSA_PRESENTATION_STYLE.md` — это система каруселей).
