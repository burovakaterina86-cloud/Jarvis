# Reels script — сценарий Reels и Stories

## Входы

- Блок «Решение по теме» (`content-strategy`) и готовый пост, если есть.
- `essa-ai/VOICE.md` — тон. Метки `[ЗАПОЛНИ: …]` → сказать, чего не хватает, не выдумывать.
- Не придумывать, что владелица делает в кадре то, чего она не делает (продукты, места, людей). Непонятно — `[уточни у владелицы]`.

> Маршрут «какой файл читать» — `essa-ai/INDEX.md`. Читай два-три названных им файла, не папку. Файлы больше ~30 КБ (склейки, `MASTER PROMPT`, `DESIGN.md`) — только `Grep`, целиком никогда.

## Reels (`reels.md`)

```
# Reels: <тема>
Длительность: 15–45 с · Формат: 9:16 · Идея в одну фразу: …

## Крючок (0–3 с)
В кадре: …
Текст на экране: <до 7 слов>
Голос: …

## Сцена 2 (3–10 с)
В кадре: …
Текст на экране: …
Голос: …

… 

## Финал (последние 3–5 с)
Призыв: …

## Подпись
<1–3 предложения + хештеги>

## Звук
<тип музыки/трендового звука; конкретный трек — только если найден в trend-radar, со ссылкой в sources.md>

## Что снять (чек-лист)
- …
```

Правила:
- Одна мысль на ролик. Крючок — в первых 3 секундах, без приветствий.
- Текст на экране читается за время сцены (≈ 3 слова в секунду).
- Каждая сцена — что конкретно снять (реально выполнимо на телефон).

## Stories (`stories.md`)

```
# Stories: <тема>

## Кадр 1
Фон/визуал: …
Текст: …
Интерактив: опрос / вопрос / слайдер / викторина / нет

## Кадр 2
…
```

- 3–5 кадров: вовлечение → суть → переход к посту/Reels → вопрос аудитории.
- Интерактив хотя бы в одном кадре.
