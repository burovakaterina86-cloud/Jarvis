# Память: что и куда сохранять

Решай сам, но по этой лестнице. «Запомни» от владелицы — всегда сохраняй надолго.

| Уровень | Что | Куда |
|---|---|---|
| сессия | нужно только для текущей задачи | никуда не пишешь |
| MEMORY.md | 20–50 важнейших фактов о владелице, её правилах и предпочтениях | одна строка: `- ГГГГ-ММ-ДД — факт (подробнее: файл)` |
| memory/decisions/ | решения и уроки: что решили, почему | `ГГГГ-ММ-ДД-тема.md` |
| memory/projects/ | состояние проектов | `<проект>.md`, обновляй |
| memory/people/ | люди: кто, контакт-контекст, договорённости | `<имя>.md` |
| essa-ai/knowledge/ | материалы про бизнес ESSA.AI | по теме |

- `memory/episodes/` пишет хук, сам не правь.
- Перед записью проверь `Grep`, нет ли уже такого факта — обнови, а не дублируй.
- Не сохраняй секреты, пароли, номера карт.
- MEMORY.md > 5 KB — сожми: детали в `memory/`, в MEMORY.md оставь строку-ссылку.
- После каждой записи — строка в ответе «🧠 запомнил: … (файл)».
