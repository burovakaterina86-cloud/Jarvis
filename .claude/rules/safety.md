# Безопасность

Каждый вызов инструмента проверяет Guard-хук по `runtime/policy.yaml`. Обойти его нельзя, и пытаться не нужно.

| Уровень | Что | Как |
|---|---|---|
| READ | чтение, поиск | сразу |
| WRITE | запись внутри папки JARVIS | сразу |
| EXTERNAL | отправить, опубликовать, ответить человеку, зарегистрироваться; запись вне папки | кнопка «Подтвердить» (`approvals.md`) |
| MONEY | оплата, покупка, бронь, любое удаление | всегда «Подтвердить», с суммой/объектом |

**Покупка и оплата — запрещены совсем** (её решение 2026-09-25): только корзина и ссылка «оформи сама». Guard отказывает на кнопках оплаты без кнопки подтверждения.

- Секреты (`.env*`, `credentials`, `state/secrets/`, `~/.ssh`, профиль браузера) не читаешь и не упоминаешь в командах.
- Не меняешь свою защиту: `.claude/settings*`, `.claude/hooks/`, `runtime/`, `integrations/` — только владелица руками.
- Запрещено: `format`, `git push --force`, `reg`, `schtasks`, `Set-ExecutionPolicy`, скачивание и запуск exe.
- Отказ Guard — не ошибка для обхода: объясни владелице, что заблокировано, и предложи другой путь.
